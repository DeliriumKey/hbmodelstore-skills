# 拟蒙特卡洛择券表现面板组件

## 计算口径

在同一券池中比较拟蒙特卡洛、双低和同券池等权组合。默认按平价分为五组，各组选前20%，组内等权、组间等权；数量向上取整。拟蒙特卡洛按市场价／理论价−1从低到高选券；双低按市场价＋100×（市场价／转股价值−1）从低到高选券。同券池等权持有各组全部合格样本。

基础样本要求市场价不高于150元、平价／纯债价值在0.5至1.5之间、剩余期限超过20天、未公告强赎且信号日有成交。按平价分组后，再剔除历史债项评级低于A−、评级缺失或正股未复权收盘价低于3元的券，筛选后不重新分组。

每10个交易日产生信号，下一交易日收盘执行，单边交易费率0.05%。各策略共用票息、停牌和退出规则：票息先确认为应收、支付日转现金，无法成交的买入留现金，停牌持仓继续计入组合；公告强赎或临近到期后在下一个可成交日退出，非正常退市未退出的剩余持仓按零计值。

超额收益＝策略净值／同券池等权净值−1。五组等权组合按调仓规则合成，不是五条净值的简单平均。目前结果截至2026年9月30日；两个起始区间分别从现金建仓，不是同一曲线截段。

## 应用场景

| 场景 | 使用方式 |
| --- | --- |
| 比较理论估值排序与双低排序的择券表现 | 在相同券池、分组、调仓与费用下对比超额收益和回撤 |
| 查看择券效果集中在哪类平价区间 | 结合五组独立组合与合成组合，区分组内选券和组间配置的影响 |
| 检查结果对起点和筛选比例的敏感性 | 比较不同起始区间与选券比例的结果，观察优势是否依赖特定设置 |

## 不适用场景

| 场景 | 原因或替代方式 |
| --- | --- |
| 直接作为当日实盘买入名单 | 面板组件展示固定规则下的历史回测，当日研究候选应由个券估值面板组件生成 |
| 把择券Q组等同于估值页Q组 | 这里按平价分组，估值页按平底溢价率分组，样本筛选也不同 |
| 用净值结果解释每笔交易的现实成交能力 | 回测采用统一费用和成交规则，实际容量需结合委托规模、盘口与市场冲击另行评估 |
