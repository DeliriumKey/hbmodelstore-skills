# 行业转债估值走势面板组件

## 计算口径

逐模型日合并全部已定价的公募可转债及公募可交债，先计算逐券市场价减理论价，再取各行业中位数，单位为每100元面值的元数值。全市场对照为全部合格样本的逐券中位数，不是各行业中位数的平均值。

行业分类默认申万2021一级行业，也支持申万2014。每个模型日使用上个季度末的正股或换股标的分类，季度内固定；缺分类的券计入“未分类”。历史统计使用当时的行业成员，缺失结果不补值。

## 应用场景

| 场景 | 使用方式 |
| --- | --- |
| 比较行业估值变化的节奏 | 在同一时间轴观察哪些行业的价差先扩大或收缩，以及行业间差距如何变化 |
| 区分市场共同变化与行业差异 | 将行业走势与全市场线对照，观察变化是否广泛同步 |
| 为截面判断补充历史背景 | 查看当前较低或较高的价差是近期形成，还是持续存在，再下钻当期个券 |

## 不适用场景

| 场景 | 原因或替代方式 |
| --- | --- |
| 把曲线涨跌当作行业转债组合收益 | 曲线是每日样本的估值中位数，不是固定组合净值 |
| 仅凭中位数变化认定同一批券全部重估 | 新券、退市与季度分类切换会改变样本；需识别驱动时下钻对应日期的个券 |
| 从行业价差反推正股行业盈利变化 | 价差同时受市场价格、模型价值和券池结构影响，不直接测量企业经营表现 |

## 查询与绘图

“看看基础化工、电子、医药生物和电力设备最近一年的转债估值走势”等请求使用本面板组件。
一次取回全部可用历史，默认控件选择近一年；近三年、全部在本地切换，不重复取数。
默认申万2021、全部券；用户给出的行业作为筛选，不指定行业时查询全部。
展示市场价减理论价中位数的历史折线，并保留全市场对照；不添加行业筛选或指标切换控件。

先用 `get_convertible_qmc_industry_dates` 取得最早、最新模型日，再传为
`get_convertible_qmc_industry_history` 的 `start`、`end`；`industries` 为逗号分隔的名称或代码。
接口直接读取预计算汇总，一次返回全部可用历史，
无需逐日读取个券截面重算。完整 MCP 结果保存为 JSON 后直接绘图；没有文件导出能力时使用包内取数脚本：

```bash
python3 "$SKILL_DIR/models/convertible-bond-qmc/scripts/query_industry.py" \
  --industries 基础化工,电子,医药生物,电力设备 --output industry-history.json
python3 "$SKILL_DIR/models/convertible-bond-qmc/scripts/visualize_industry_history.py" \
  --input industry-history.json --output industry-history.html
```

取数脚本默认自动查询完整日期范围；确需限定导出数据时可传 `--start`、`--end`。
`--industry-standard SW2014` 切换分类，`--industries none` 为全部行业。
开发验收时取数脚本读取任务环境 `HBMODELSTORE_API_ORIGIN`，或显式传 `--api-origin`；
未设置时使用公网默认服务。
已有完整 JSON 时只运行绘图命令。输出复用网站的 `industry-history.mjs`，保留缺值与真实日期。
需要解读行业差异和变化时，另读[行业与个券分析指引](../analysis/valuation-review.md)。
