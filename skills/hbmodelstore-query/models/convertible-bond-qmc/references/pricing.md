# 个券拟蒙特卡洛估值面板组件

## 计算口径

使用同一模型日的完整已定价截面，默认最新模型日、全部券。理论溢价率＝市场价／理论价−1；数值越低，相对模型理论价值越便宜。价格均为每100元面值的元数值。

市场价减纯债价值是价格高于债底的金额，市场价／纯债价值−1是纯债溢价率。
同等信用等条件下，价格越接近债底，回落至债底的幅度越小；价差越大，
为转股机会支付的额外价格越高，而不是保护越厚。纯债价值是模型条件下的债券价值。

平底溢价率＝平价／纯债价值−1。对平价、纯债价值均有效且大于零的券，从低到高等分为Q1–Q5；并列值按代码排序，不能整除时前面的组各多一只。先在完整截面分组，再按行业、券类型或名称筛选，筛选后不重新分组。缺少有效分组值的券保留在“全部”中。

行业使用上个季度末的正股或换股标的申万一级分类，默认2021，也支持2014。已公告强赎券使用单独定价方法，结果不提供模拟路径的强赎终止、下修比例。

## 应用场景

| 场景 | 使用方式 |
| --- | --- |
| 从相近股债属性的券中寻找研究候选 | 在同一平底溢价率组内比较理论溢价率，再结合市场价、平价、纯债价值及条款筛选 |
| 复核某只券的估值偏离 | 同时查看市场价、理论价和近期历史，判断偏离是持续存在还是近期出现 |
| 从行业判断下钻到个券 | 筛选行业后比较组内个券，检查行业估值是否由少数极值推动 |

## 不适用场景

| 场景 | 原因或替代方式 |
| --- | --- |
| 把估值页Q组直接当作择券回测的Q组 | 估值页按平底溢价率分组；择券表现按平价分组，且另有价格、评级和正股价格筛选 |
| 把模拟比例当作现实发生概率或条款价格贡献 | 路径比例描述模型设定下的模拟结果；条款贡献需另做定价对照，现实事件需结合公告判断 |
| 直接把最大折价作为买入顺序 | 排序衡量相对模型价值，实际交易还需结合信用、条款、流动性及模型输入判断 |

## 查询与绘图

“看看转债的拟蒙特卡洛估值”使用本面板组件。按[完整截面查询](query.md)读取同日全部分页，保存
`cross-section.json`；不套用市场面板组件的70–130元平价筛选。

```bash
python3 "$SKILL_DIR/models/convertible-bond-qmc/scripts/visualize.py" \
  --input cross-section.json --output pricing.html
```

`--group q3` 预选组；`--industry SW2021:行业代码`、`--bond-type cb`、`--query 名称或代码`
预选筛选条件，`--sort 字段名`、`--descending` 调整排序。默认20行分页，支持搜索、排序、Q组切换和详情。
分组按钮只写“全部、Q1…Q5”，不附加券数、范围或中位数统计行。完整数据、分组与格式化沿用包内 renderer。

研究中展示一组个券的估值截面时，转债名称沿横轴排列，使用竖柱、负值向下，采用
[共用绘图入口](../../../references/chart-runtime.md)的 `category-bars` 单元。
重点券用 `highlight` 在同一数据系列内变色，代码留在悬停提示中。个券数量增加时横轴名称正向竖排、不倾斜，
保持横版画布；行业汇总仍沿用现有横向条形图，个券历史仍用折线。

需个券历史时，用 `get_convertible_qmc_history` 查询截至截面日的最近一年，逐券保存完整响应；
以 `--history bond-history.json` 追加，可重复；`--dates dates.json` 接收 `get_convertible_qmc_dates` 的完整日期响应。
历史图可切换市场价与理论价、理论溢价率；未附历史时只展示已有详情，缺失模型日留空。
离线页使用输入分类版本，切换版本需重新导出，不在旧数据上改标签。
结果解读另读[行业与个券分析](../analysis/valuation-review.md)。
