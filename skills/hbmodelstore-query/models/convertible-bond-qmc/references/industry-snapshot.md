# 行业转债估值截面面板组件

## 计算口径

按同一模型日全部已定价的公募可转债及公募可交债汇总，不做Q组筛选。默认最新完整模型日、申万2021一级行业，可切换申万2014。采用正股或换股标的上个季度末的分类，季度内固定；缺分类的券单列“未分类”。

先逐券计算市场价减理论价，再取行业中位数，单位为每100元面值的元数值。负值表示市场价低于模型理论价，正值表示高于理论价。

平底溢价率＝平价／纯债价值−1，先逐券计算再取行业中位数。缺少平价或有效纯债价值的券不参与该指标，但仍计入行业已定价券数。

## 应用场景

| 场景 | 使用方式 |
| --- | --- |
| 比较最新各行业的相对估值 | 按价差中位数定位折价或较低溢价集中在哪些行业 |
| 理解行业内转债的股债属性 | 结合平底溢价率中位数观察平价相对债底的位置，区分估值差异与股债属性差异 |
| 确定后续研究对象 | 结合行业券数选择下钻范围，再到个券面板组件查看分布、代表券与条款 |

## 不适用场景

| 场景 | 原因或替代方式 |
| --- | --- |
| 用一个截面判断行业估值已经扩张或收缩 | 截面只比较当日位置；变化应使用行业估值走势图 |
| 把行业中位数当成所有券的共同特征 | 中位数不展示行业内的离散程度，少量样本或明显分化需要查看个券 |
| 以价差直接衡量行业回报率或股票行业前景 | 指标是每百元面值的定价差，不是收益率，也不是正股行业盈利预测 |

## 查询与绘图

“看看最新的各行业转债估值截面”使用本面板组件，默认值由面板组件承接，不要求用户列出字段和排序。
网站用 `get_convertible_qmc_industry_dates` 对应日期和 `get_convertible_qmc_industry_history`
的单日汇总（`start=end`、`industries=none`）；生成离线网页时，现有导出器接收
[完整同日个券截面](query.md)，使用同一逐券中位数口径：

```bash
python3 "$SKILL_DIR/models/convertible-bond-qmc/scripts/visualize.py" \
  --input cross-section.json --view industry --output industry.html
```

默认全部券，不传 `--bond-type` 或Q组筛选；旧状态中的 `group` 不限制行业样本。
保留 `industry_standard`、行业代码、`industry_as_of_date` 和模型版本。离线页沿用输入分类版本，
换版本需重新导出。接口通过统一 API/MCP 查询。
输出是行业横向柱状图和汇总表，不默认追加个券名单。分析指引见[行业与个券比较](../analysis/valuation-review.md)。

## 可选分布图

只数与余额分布默认隐藏，明确需要时加 `--show-distribution`；饼图展示前十大行业，其余合并“其他”，
估值图和表仍保留全部行业。有同日完整余额时加 `--balances balances.json`，分别展示只数和余额占比，行业同色。
余额输入为 `{"model_date":"YYYY-MM-DD","unit":"CNY_100M","rows":[{"bond_code":"代码","outstanding_balance":余额}]}`，
单位亿元，覆盖截面全部代码，日期一致，无重复、负值和缺失值。当前模型API不提供余额，需另行取得，
不以发行规模或别日余额代替。
