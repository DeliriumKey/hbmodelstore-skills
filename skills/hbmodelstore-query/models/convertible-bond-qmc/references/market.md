# 市场拟蒙特卡洛估值面板组件

## 计算口径

市场理论溢价率为逐券“市场价／理论价−1”的等权平均。公募可转债与公募可交债合并为同一券池，要求市场价、理论价、转股价值均有效，并统一保留平价大于70元、小于130元、实际转股溢价率低于85%的券。不做百元溢价率回归的残差剔除。

实际转股溢价率＝市场价／平价−1，理论转股溢价率＝理论价／平价−1；二者的分母都是平价，
与市场理论溢价率的比较对象不同。平价下跌也可使转股溢价率上升，单看比率不足以确定价格涨跌。

以模型理论价为参照，理论溢价率高于0%表示溢价，低于0%表示折价。高于+3%标为偏贵，低于−3%标为便宜，其间为正常。

同一筛选下，每日按平价／纯债价值从低到高等分为低、中、高三组，逐组计算理论溢价率等权均值。相同值按代码排序，余数依次分给低、中组；纯债价值无效的券不参与分组，但仍可进入整体曲线，不足三只时不作三组比较。

分组“原始值”表示相对理论价的溢折价；“相对历史”先扣除当日三组简单均值，再扣除此前252个模型日的自身均值。负值表示较该组历史常态相对便宜。窗口不含当日，历史不足或缺值时留空。分组每日更新，不是固定持仓组合。

百元溢价率保留自身拟合样本。市场隐含波动率来自中证1000股指期权（MO）的Heston校准，短期为 $\sqrt{v_0}$，长期为 $\sqrt{\theta}$，均以年化百分比展示。

## 应用场景

| 场景 | 使用方式 |
| --- | --- |
| 判断转债整体相对模型价值的贵便宜 | 结合理论溢价率与观察分界判断当前水平，不只比较历史高低 |
| 比较股票与转债的长期配置价值 | 其他条件相近时，溢价越高，为债底保护与转股机会支付的额外价格越高 |
| 观察估值扩张、收缩与市场内部差异 | 结合整体走势和三组曲线，区分共同变化与某类券的相对变化 |
| 辅助观察波动环境 | 期权校准波动率作为背景现象展示；配置判断使用理论估值、动量与分组差异，波动率不承担投资结论 |

## 不适用场景

| 场景 | 原因或替代方式 |
| --- | --- |
| 用市场均值替代个券判断 | 个券可能与市场方向不同，择券需查看个券理论溢价率、条款与历史 |
| 将估值动量直接当作短期价格预测 | 溢价变化与正股涨跌共同影响转债价格，估值收缩本身不是买卖时点 |
| 将分组曲线当作可投资组合收益 | 每日重新分组，曲线是当日样本的估值统计；策略收益应查看择券回测 |
| 把期权校准波动率当作转债隐含波动率 | 两者的市场和定价对象不同，该序列反映MO期权的校准结果 |

## 查询与绘图

普通查数直接使用 MCP：

- `get_convertible_qmc_market_history`：可选日期、券种、平价上下限及转股溢价率上限；参数以 MCP 工具定义为准。不传样本筛选条件时返回全部有效券的聚合。
- `get_convertible_qmc_market_groups_history`：同样的筛选参数，返回每日低、中、高三组的理论溢价率、相对历史值与券数。
- `get_convertible_qmc_market_volatility_history(start=..., end=...)`：中证1000股指期权校准时序。
- `get_convertible_premium_history(start=..., end=...)`：同区间的百元溢价率对照。

QMC 查询默认最近3660个自然日，指定区间也不超过这一上限。均返回 `rows`，以 `model_date` 对齐。
市场预览默认不指定起止日期，读取可用历史；百元溢价率与波动率按市场结果的首末日期查询。
市场分析将可转债与可交债合并，不传 `bond_type`，不分别生成券种曲线。与网页一致，统一使用 `parity_min=70, parity_max=130, conversion_premium_max=85`，筛选后逐券等权。

字段含义与市场汇总公式按 [模型入口](../MODEL.md) 读取构建文档的“结果解读”。
溢价率、波动率都是百分数数值，例如 `25` 显示为 `25%`，不再乘100。

### 分组取数

使用 `get_convertible_qmc_market_groups_history`，传入与整体市场相同的日期和筛选条件。
日度分组由服务端计算，不逐日下载截面，也不依赖本地预制数据。需要下钻组内个券时，
再用 `get_convertible_qmc_cross_section` 读取完整截面。

相对历史比较直接使用 API 的 `low_relative_pp`、`mid_relative_pp`、`high_relative_pp`，单位为百分点。
服务端自动补足此前计算窗口，客户端不再减均值。`low_pct`、`mid_pct`、`high_pct` 保留原始值。

### 导出

将四个完整 MCP 对象分别保存在 `market`、`groups`、`premium`、`volatility` 键下，形成 `market.json`。
有快照时直接复用；需要一次性落盘可用标准库脚本：

```bash
python3 "$SKILL_DIR/models/convertible-bond-qmc/scripts/query_market.py" \
  --output market.json
python3 "$SKILL_DIR/models/convertible-bond-qmc/scripts/visualize_market.py" \
  --input market.json --output market.html
```

默认取全部可用历史，只有用户指定查询区间时才加 `--start` / `--end`；市场脚本不提供券种切换。
脚本默认带上述样本筛选，可用 `--parity-min`、`--parity-max`、`--conversion-premium-max` 改阈值，或用 `--all-samples` 取消全部样本筛选；可转债与可交债始终适用相同规则。三个溢价率及价差始终使用同一券池；百元溢价率对照与指数期权波动率不随这些筛选变化。
网页使用同源 renderer：依次展示理论溢价率、分组理论溢价率、百元溢价率、短期与长期波动率，四图光标与区间联动。分组图默认“相对历史”，可切换“原始值”；相对历史只画零线，不套用绝对估值阈值。整体理论溢价率以无文字的灰色虚线标记 ±3% 观察分界；低于 −3% 用浅绿底色，高于 +3% 用浅红底色，低于 −5% 或高于 +5% 时底色加深。百元溢价率图同步这些日期分档。
默认显示“全部”，近一年、近三年只切换展示范围，不在取数时截短历史。
默认在 Agent Harness 侧边栏打开 HTML；正文需要图时按[绘图运行环境](../../../references/chart-runtime.md)选择 `#valuation`（市场估值）、`#groups`（分组估值）或 `#premium`（百元溢价率）导出无标题、无脚注的 PNG，插在相关段落之间。缺失日期留空，不前填。
需要解释当前水平、动量及三组差异时，另读[市场分析指引](../analysis/market-valuation.md)。

### 估值与价格动量同图

研究估值与趋势共振时，复用本面板组件内的 `assets/market-momentum.mjs` 绘图单元。
市场理论溢价率用红线，931078指数20日动量用黑线，共用百分比轴；零参考线为灰色实线，不单列图例。
仅在“折价且动量向上”时用浅绿背景、“溢价且动量向下”时用浅红背景。
两项均以0为分界，其余两种组合、零值和任一指标缺失的日期留白，连续同状态合并为区间。

取同一区间的市场估值及[指数动量历史](../../convertible-bond-premium/references/index-momentum.md)，
将完整响应放入 `data.market`、`data.momentum`，外层 `title`、`note` 用于 HTML 标题与来源日期。
按实际日期对齐，缺值保留断线。绘图单元直接使用接口的 `momentum_pct`，不从个券价格另算代理动量。

```bash
node "$SKILL_DIR/assets/charts/render.mjs" \
  --module "$SKILL_DIR/models/convertible-bond-qmc/assets/market-momentum.mjs" \
  --input market-momentum.json --output market-momentum \
  --height 340 --web-height 340
```

HTML 与 PNG/SVG 使用同一绘图函数；正文 PNG 只展示图，不包含标题或脚注。
