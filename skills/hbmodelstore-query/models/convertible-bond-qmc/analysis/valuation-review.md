# 行业与个券比较

涉及行业、个券或区间估值差异的解读时参考；按问题选用，不要求完整复盘。
回答“哪些券相对便宜、便宜集中在哪些价格或平价区间、哪些行业”。查询按
[个券查询](../references/query.md) 执行，读取同一模型日的完整截面；指定单券时按问题裁剪。
成篇分析的标题按 [MODEL.md](../MODEL.md#成稿标题) 的固定主题与可选判断规则，不把下面每项分析步骤都拆成栏目。

本场景独立回答行业与个券的横向差异，需要 Panel 时使用个券估值交互网页；不默认补写市场整体估值、
高中低三组或另生成市场网页。用户同时询问市场时才组合[市场估值分析](market-valuation.md)。

## 分析思路

先找便宜集中在哪里，再下钻到代表券，不只交付最低溢价率排行榜。

| 主线 | 要回答的问题 |
| --- | --- |
| 区间比较 | 哪些价格、平价区间的理论溢价率较低？组内多数券如此，还是少数极值拉低均值？ |
| 行业比较 | 哪些正股行业的价差中位数较低？折价集中于少数券，还是行业内较普遍？ |
| 个券筛选 | 哪些券既低于理论价，又低于相近样本？偏离是持续存在，还是近期出现？ |

区间与个券以理论溢价率从低到高比较，行业以价差中位数比较。两者负值均表示低于理论价，
组间更低但仍为正时写“相对较便宜”。低市场价、低转股溢价率本身不等于低估。
市场整体与高、中、低三组沿用[市场估值分析](market-valuation.md)，不改用价差判断。

## 比较方式

- 个券分析默认保留全部已定价样本，不套用市场预览的 70–130 平价筛选，否则无法比较高低区间。
  价格与平价分别分组，不混成一种“高价”。分界在比较前确定，同次分析保持一致。
- 如果问题承接市场预览的高、中、低价组，则保留市场筛选与每日平价／纯债价值三等分口径，
  在该组中下钻代表券，不改成市价分档或全部样本。分组步骤见[市场查询](../references/market.md)。
- 价格本身进入理论溢价率的分子，价格分组用于描述分布；区间差异再用平价分组交叉检查，
  不把它直接解释为低价策略有效。
- 区间分组列券数、理论溢价率中位数与等权均值、低于理论价的券数占比；用中位数和组内分布判断
  是否普遍便宜。发现均值与中位数分歧时下钻极值，少量样本不概括为整个行业特征。
- 从较便宜的组中选代表券，同时检查全截面的低溢价率券，避免遗漏组外个券。
  结合市场价、理论价、平价、纯债价值和近期历史解释偏离；强赎与下修路径比例只描述模拟特征，
  不换算成条款价格贡献。已公告强赎券单列，普通转债与可交债保留身份。

## 行业比较

- 默认使用全部已定价截面；用户指定范围时沿用该范围。按正股／换股标的的
  `industry_standard` 和 `industry_code` 分组，名称用于展示，缺失映射单列。
- 以 `market_minus_theoretical`（市场价减理论价，每百元面值的元数值）的行业中位数
  从低到高比较。负值表示典型个券低于理论价，正值较小只表示相对便宜；不套用市场溢价率的百分比阈值。
- 表格列行业、券数、价差中位数、低于理论价的券数占比、理论溢价率中位数和平价中位数。
  后两项仅作展示，不参与行业排序、评分或贵便宜判断，不据平价中枢再作匹配调整。
- 结论围绕价差中位数，结合折价占比和代表券说明便宜是否普遍；不以平均价差代替中位数，
  少量样本不概括为整个行业特征。

## 表达方式

对“整体贵不贵、哪组相对便宜、哪些行业和个券便宜”这类综合问题，默认只展示三张表：
三组估值（`groups`）、行业比较（`industries`）、个券名单（`bonds`）。整体与三组判断用一段话说明。
市价区间、平价区间和个券历史可用于内部分析，不因计算过就附表；用户追问相应维度，
或确需单独展示某个异常时再补充。只问其中一项时只展示相关表格，不凑齐三张。

表格用[分析表格脚本](../references/query.md#分析表格)直接生成 Markdown，保持脚本输出的列与数值格式，
不在单元格补充其他信息。正文先指出便宜集中在哪里，再解释支持与反例。
正文围绕比较后的含义展开：便宜是否普遍、哪些个券是例外、折价是持续存在还是近期扩大，
不把各行的中位数、均值、占比和历史值重新列一遍。各段承接前一段的问题，再收敛到研究候选。
综合分析可从整体与三组的判断推进到行业和个券，按实际问题合并或调整章节，不写空章节。
名单是相对模型价值的研究候选，不把最大折价直接等同于最值得买入。
