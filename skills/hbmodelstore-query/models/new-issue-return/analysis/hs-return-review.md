# 沪深打新收益分析

涉及沪深网下打新收益、两市贡献、底仓选择或规模与风险关系时参考；按问题选用，不要求完整复盘。
查询与绘图按 [MODEL.md](../MODEL.md)，共用[收益回顾与可持续性](./return-review.md)的判断依据。

## 收益与两市贡献

用户未指定时采用沪深双打、A 类、2 亿元合计账户规模，其余参数沿用计算脚本默认值。
近期分析以最近完整月为主，与上月及此前三个月月均比较；季度或年度问题按指定区间回顾。
需要收益对比表时，用一张表呈现主要数字，正文解释变化，不复述表格。

双打的沪市、深市贡献直接从同一场景的 `details` 按证券代码后缀 `.SH`、`.SZ` 汇总，
各自收益除以同一个合计账户规模。不要用两个单打结果相加代替双打，单打与双打的申报预算不同。
一市明显主导收益或两市方向不同时，再列两市的收益金额、账户贡献和项目数；否则一句话概括即可。
价格和配售统计按市场分别看，首日涨幅不直接等同于账户收益贡献。

## 收益支撑

判断收益改善来自更多发行、单笔获配增加，还是首日溢价扩大；若依赖少数项目，说明这种集中性。
比较规模时区分收益金额与贡献率：触及申购上限后，规模增加可能无法带来同比例的收益增长。
用户未问规模比较时不另外扩展一组测算。

## 底仓与策略价值

讨论打新产品“值不值得投”时，研究对象是包含底仓的完整产品。底仓与打新共同构成产品的收益与风险，
投资者购买的是这一整体。判断围绕完整产品的收益、回撤和配置价值展开；拆分打新贡献是为了说明
收益来源、规模效应与下跌缓冲，而不是让投资者先决定是否单独需要股票底仓。

沪深300指数增强可以作为具体研究场景：区分指数市场收益、股票增强收益和打新贡献，
按实际资金占比换算到同一账户规模。这里的底仓是产品内部的股票组合；研究现成指增基金时，
基金净值已包含自身打新结果，模型测算用于解释和比较打新贡献，避免重复相加。
指数只能作为市场收益参照，股票增强部分需由具体策略或产品数据支持。
需要底仓市场收益与回撤数据时，按[底仓指数公开接口](../references/underlying-indices.md)取沪深300、上证50等真实行情，按讨论对象选择，不要求每次全部比较。

底仓比例优先采用用户给定条件、产品持仓或合同约定。构造代表性情景时，说明它对应的产品类型和
选择依据；没有代表性依据时，可做仓位参数对比，结论落在各自假设下。申报预算比例与股票底仓比例
分别设置，纯打新工具的默认预算和账户规模门槛不代表产品的股票仓位或法定市值要求。

比较完整产品时，在计算前确定各方案的底仓组成、可参与市场、配售身份和账户分母，再用
`analyze.py --scope sh/sz/dual` 分别计算匹配的打新收益。仅持有上证50股票的情景匹配沪市打新；
若研究沪深双打产品，则明确其深市底仓及相应权重，一并计入收益路径。沪深300指数作为双打底仓
参照时，也需说明分市场持股市值达标的情景依据，指数名称本身不证明资格。
只想隔离比较指数风险时，可以固定同一份打新增量；此时呈现为底仓风险对照，结论回答指数差异，
与可实施产品的整体收益比较分开。

比较规模时，同时考虑打新收益摊薄与沪深两市各自的股票市值要求。模型的双打起点与底仓各半
是测算设定，实际资格、投资者类别和可用额度按产品身份及发行规则核对。
讨论下跌保护时，比较同一期间的底仓损益和打新贡献；如计算组合回撤，使用对齐的收益路径与
明确的仓位、再投资假设。累计打新收益可以缓冲损失，但不是最大回撤的直接抵减额。
缺少具体产品数据时，先回答能支持的机制与取舍，再按用户意愿补查，情景假设与实际业绩分开呈现。

## 多轮研究

首轮围绕当前打新收益和投资价值回答，开头概括证据支持的主要变化或配置取舍，后续根据发现自然引向底仓、规模或下跌风险。
用户提出沪深300指增时，就沿这条组合思路深入；每轮推进一个尚未解决的问题，复用已有数据与面板组件。
在评价产品时，把底仓策略、打新增量和规模效应分别讲清，再合起来判断产品整体的收益风险特征、
与同类产品的差异及在组合中的配置作用。底仓比例与管理方式按所讨论的产品设定。

需要图表时，默认交付一个沪深双打 Panel，使用 `analyze.py --market hs --scope dual` 与 `visualize.py`。
用户需要分别看两市图表时再展开相应 Panel，回答围绕当期收益、两市贡献或持续性中的当前问题组织。
