# 沪深打新收益分析

涉及沪深网下打新收益、两市贡献或收益变化原因的解读时参考；按问题选用，不要求完整复盘。
查询与绘图按 [MODEL.md](../MODEL.md)，共用[收益回顾与可持续性](./return-review.md)的组织与成稿规则。

## 收益与两市贡献

用户未指定时采用沪深双打、A 类、2 亿元合计账户规模，其余参数沿用计算脚本默认值。
近期分析以最近完整月为主，与上月及此前三个月月均比较；季度或年度问题按指定区间回顾。
需要收益对比表时，用一张表呈现主要数字，正文解释变化，不复述表格。

双打的沪市、深市贡献直接从同一场景的 `details` 按证券代码后缀 `.SH`、`.SZ` 汇总，
各自收益除以同一个合计账户规模。不要用两个单打结果相加代替双打，单打与双打的申报预算不同。
一市明显主导收益或两市方向不同时，再列两市的收益金额、账户贡献和项目数；否则一句话概括即可。
价格和配售统计按市场分别看，首日涨幅不直接等同于账户收益贡献。

## 收益支撑

判断收益改善来自更多发行、单笔获配增加，还是首日溢价扩大；若依赖少数项目，说明这种集中性。
比较规模时区分收益金额与贡献率：触及申购上限后，规模增加可能无法带来同比例的收益增长。
用户未问规模比较时不另外扩展一组测算。

需要图表时，默认交付一个沪深双打 Panel，使用 `analyze.py --market hs --scope dual` 与 `visualize.py`。
只有用户明确要求分别看两市图表时才另出两个 Panel。主题仍为“收益回顾”“收益结构”“可持续性分析”，
不另外增加市场介绍或操作教程。
