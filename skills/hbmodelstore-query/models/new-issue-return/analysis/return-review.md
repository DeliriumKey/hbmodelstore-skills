# 打新收益回顾与可持续性

涉及沪深与北交所打新收益、变化原因或持续性的解读时参考；按问题选用，不要求完整复盘。
回答“这段时间收益怎么样，以及支撑收益的条件有没有变化”，只展开相关部分，不额外组织一份市场跟踪或项目分析。

沪深任务同时读[沪深打新](./hs-return-review.md)，北交所直接使用本页。

## 准备事实

查询和绘图按 [MODEL.md](../MODEL.md)；复用已有发行表、`analyze.py` 结果和
[统计工具](../references/review.md)，不重复取数。方法与窗口含义按模型入口读取文档 MCP。
保持比较中的市场、规模、价格、预算和投资者类别一致；沪深与北交所分别分析。
沪深双打可以合计收益，价格与破发判断仍分沪、深核对。

近期问题以最近完整自然月及上月、较长参照为主，读取 `monthly_tracking.target` 与 `baselines`；
先确认实际覆盖，不能用更新时间或改写 `end` 代替补齐。月内数据只补充新变化，不与完整月累计收益
直接比高低。历史复盘按用户区间展开，不因文件覆盖多年就默认分析全历史。

## 收益回顾

先说明理论收益金额、对账户的贡献，以及相对此前是在改善、平稳还是收窄。
用项目数量与单项目贡献区分“参与机会变多”与“每次申购更赚钱”，各个参照分别判断。
只有解释变化需要时，再看配售率、获配金额和首日价格表现，不逐项完成一套指标点评。

完整收益回顾默认用一张紧凑的收益对比表承载主要数字，简短解读不强制附表：列为所选期间与必要参照，行优先放理论收益金额、
理论打新贡献、项目数与单项目贡献。价格或配售指标确有解释力时再加入，不机械放齐所有字段。
多月参照的金额、贡献和项目数用月均；价格与配售率是合并项目的中位数，不能标成月均。

不默认设置项目对照章节或项目表。仅当收益由少数大额贡献支撑、个别亏损明显侵蚀收益，
或异常项目改变了总体判断时下钻；一句话能解释就不另列表，也不为演示“涨幅高不等于贡献大”专门挑例子。

## 可持续性

北交所后续收益判断先区分申购制度：历史结果解释现金申购下的收益；涉及市值配售时，先核对交易所正式规则及生效日期。若采用市值配售，打新贡献需按持股市值、申购额度与新的配售规则重新测算，策略总收益还需计入股票底仓盈亏。应讲清这意味着原先不承担股票底仓波动的现金打新方式无法原样延续；已有股票底仓的组合可评估新增打新贡献，为打新新建底仓的组合则需同时评估底仓风险。当前模型尚未覆盖市值配售，历史结果作为现金申购制度下的参照。

讨论现有现金打新模式时，把申购期间需准备或冻结的资金与最终获配缴款区分开。
发行表的获配金额用于计算收益，实际资金周转还取决于申购日程、退款安排及同时申购的项目。
评价“低风险”时说明其来自不承担股票底仓波动，仍需结合新股上市表现判断损失风险。

用户追问改革影响时，沿“收益怎样重算、原有低风险特征怎样改变、哪些组合仍适合参与”展开。
已明确的改革方向支持机制分析；市值范围、持有期限、额度换算、配售及缴款安排按正式细则确认。
把原有现金打新资金与本来就持有合资格股票的组合分别讨论，帮助用户判断是新增股票风险，还是获得附加打新收益。

从回顾中的变化判断收益的支撑是否稳固：发行机会是否增加、单笔贡献是否变薄，
配售与获配是否收缩，价格表现尤其是较弱项目是否出现承压。只展开真正影响结论的线索。
例如总收益平稳但依赖更多项目补足单笔下降，应指出其对发行数量的依赖，而非只报“收益平稳”。

破发压力是持续性的一部分，不另起一套与收益脱节的分析。没有破发只说明已观察样本未破发；
结合弱端表现判断压力，不将零破发写成未来安全，也不把配售率升降直接当作价格风险。
价格、配售与贡献并不必然同向，不将几个中位数相乘当归因。单月改善与长期趋势分开，
发行表没有提供未来发行供给、估值或流动性证据时，不据此给出确定的未来收益或暂停申购指令。

## 研究呈现

标题、交互网页与对话交付沿用根 Skill。收益水平、结构和可持续性是研究问题，按本轮需要选择，
而不是固定的成稿栏目。先给当前判断，再用必要的比较解释；表格承载数值，文字说明含义。
当前收益已清楚时，可结合发现邀请用户进一步比较账户规模或核对影响收益的项目；
后续研究服务于尚未解决的决策问题。
北交所还可自然追问市值配售对现有模式的影响。评价打新产品时，围绕改革前后完整产品的收益来源、
底仓风险与策略定位展开；用户明确研究自营账户时，再结合该账户现有持仓和资金安排讨论。
历史测算组件随对话复用，改革后的未知参数作为待核对事项，不用假定参数生成看似确定的新制度收益。

规模比较、实盘或研报核对只在用户需要时进行，见[按需核对](../references/review.md#按需核对)。
