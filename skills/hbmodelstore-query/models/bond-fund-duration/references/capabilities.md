# 功能支持

## 已发布为公网 API

| 用户需求 | 客户端命令 | 说明 |
| --- | --- | --- |
| 查询单只或多只基金最新久期 | `query.py latest` | 最多 200 只基金 |
| 查询单只基金历史久期 | `query.py history` | 最长十年、最多 2,500 行 |
| 查询当前久期截面 | `query.py cross-section` | 支持分布统计和高久期名单 |

## 尚未发布为公网 API

- 当前样本分类和历史分类区间；
- 报告期披露久期与模型久期比较；
- 市场或自定义基金池的历史久期中位数；
- 判断基金何时开始增加久期的综合分析；
- 正式模型参数、拟合诊断、任务状态和收益异动结果。

这些能力即使在旧模型项目中已有数据库查询或分析脚本，也不要从统一用户 Skill 直接调用。
先在服务端发布受约束路由、将接口补充到模型根目录的 `api.md`、增加客户端命令和真实接口
测试，再更新本文件。
