# 百元溢价率面板组件

## 计算口径

按交易日合并当时已上市且未退出的公募可转债及公募可交债，使用有效行情，保留平价大于70元、小于130元、转股溢价率低于85%的样本。

以平价 $V$ 和转股溢价率 $p$ 拟合带截距的反比例模型 $p=c+a/(V/100)$。先做普通最小二乘拟合，再剔除绝对残差高于90%分位点的样本重新拟合；两次均不按规模加权。

最终曲线在平价100元处的拟合转股溢价率，即 $\widehat p_{100}=\widehat c+\widehat a$，为当日百元溢价率。拟合券数是第二次拟合实际使用的样本数。历史分位是所选区间中不高于当前值的观测占比，随展示区间变化。

## 应用场景

| 场景 | 使用方式 |
| --- | --- |
| 比较不同时点的转债估值 | 在统一的100元平价位置比较溢价，观察市场估值扩张、收缩及其历史位置 |
| 衡量股票与转债的相对性价比 | 其他条件相近时，溢价越低，为转债支付的额外价格越少，用于股票与转债之间的长期配置比较 |
| 观察市场情绪 | 将溢价水平及其变化作为市场支付意愿和需求变化的参考，结合期限、信用与条款结构理解 |

## 不适用场景

| 场景 | 原因或替代方式 |
| --- | --- |
| 仅凭历史分位判断绝对贵贱 | 百元溢价率没有理论价值对应的贵贱分界；需要理论价值参照时使用市场拟蒙特卡洛估值 |
| 依据拟合曲线上下位置择券，或比较高低价券的相对价值 | 整体曲线没有逐券处理期限和条款差异；此类比较使用个券理论定价及相近样本分组 |
| 直接预测短期价格涨跌 | 指标描述当前溢价与历史位置，短期收益还取决于正股走势和估值后续变化 |

## 查询与绘图

普通查询用 `get_convertible_premium_info`、`get_convertible_premium_history`；单日曲线用
`get_convertible_premium_curve`，指定日期无结果时不自动回退。参数与限额以 MCP schema 为准。

生成可切换区间的历史图时，先从 info 取得真实起止日期，再用 `start/end` 查询全部可用历史。
默认显示近三年，近一年、全部在本地切换。仅查数时按用户区间查询，不强制全量。
将完整历史响应保存为 `history.json`：

```bash
python3 "$SKILL_DIR/models/convertible-bond-premium/scripts/visualize.py" \
  --input history.json --output premium.html
```

优先在客户端侧边栏打开。历史红线为百元溢价率，右轴灰色面积为拟合券数；离线页另保留单日曲线，
从已发布系数计算展示点，不重新回归或取数。字段与百分数格式见 [fields.md](fields.md)。
需要解读时参考[市场分析指引](../../convertible-bond-qmc/analysis/market-valuation.md)中百元溢价率的用法，不因此补查全部 QMC 数据。
