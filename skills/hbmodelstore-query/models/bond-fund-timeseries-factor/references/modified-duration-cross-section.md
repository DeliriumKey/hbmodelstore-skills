# 修正久期截面

## 功能

查询一个真实模型日的全部基金修正久期，用于排序、分位数或自定义基金池比较。

## 典型请求

- “查 2025-01-02 的全部基金修正久期。”
- “给我最新模型日久期最高的 10 只基金。”

## 输入与默认值

`--date` 可省略；省略时查询共同最新模型日，提供时必须精确匹配已发布模型日期。

```bash
python3 skills/hbmodelstore-query/models/bond-fund-timeseries-factor/scripts/query.py \
  cross-section --date 2025-01-02
```

## 返回

返回 `model_date` 与完整 `rows`，基金代码统一为六位代码加大写 `.OF`。排名、分位数和自定义
基金池筛选在完整响应上本地计算，不调用旧统计路由。

## 可视化

当前没有固定网页图或独立 renderer；按用户需求对截面做有界表格或一次性统计即可。

## 边界

- 指定日期没有结果时返回空 `rows`，不得自动改用前一个交易日。
- 截面只代表该日模型结果，不代表真实持仓或未来收益预测。
