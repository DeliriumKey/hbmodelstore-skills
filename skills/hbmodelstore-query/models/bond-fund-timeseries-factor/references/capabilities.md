# 功能支持

## 已发布为公网 API

| 用户需求 | 客户端命令 | 说明 |
| --- | --- | --- |
| 查询指定日期的全部基金修正久期截面 | `query.py cross-section --date ...` | 省略日期时查询共同最新模型日期 |
| 查询一只或多只基金修正久期历史 | `query.py history --fund-code ...` | 多只代码用英文逗号分隔，起止日期均可省略 |
| 查询纯债基金分组修正久期中位数历史 | `query.py median --breakdown ...` | 默认按利率/信用分支，可进一步拆分中长期/短期纯债类型 |

## 尚未发布为公网 API
