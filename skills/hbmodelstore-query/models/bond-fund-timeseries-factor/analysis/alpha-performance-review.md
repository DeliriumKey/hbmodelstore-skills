# Alpha 表现复盘

仅在用户要求分析 Alpha、收益优势或近期表现时读取。本页指导文字分析；查询与绘图按
[MODEL.md](../MODEL.md) 的 Alpha 入口执行，已有完整结果直接复用。

## 分析思路

帮助读者理解：基金在模型考虑期限与信用风险后，收益优势如何、是否持续，近期是在改善还是减弱。
完整复盘先建立全程总览：长期增值的底色是什么，优势怎样起伏，当前处于这段历程的哪里。
完整历程文章按“全程总览—阶段演变—当前表现与配置背景”组织，章节标题结合实际发现命名。
全程总览概括整体收益特征；阶段演变在同一个章节内用连贯段落交代历史；
最后解释当前长短期表现及相关配置背景，承接前文而不重复历史。
专项问题可按范围裁剪，篇幅随实际发现伸缩。阶段分析采用文字，不写阶段表格。

阶段按 Alpha 水平、相对位置和长短期关系的持续变化划分，例如优势形成、走弱、恢复或再度收窄，
不预设阶段数量，也不机械按年度拆分。相邻时期若没有改变主要判断，可以合并叙述，
短暂波动作为阶段内的补充，重要低谷与转折保留。各阶段共同交代全部可用历史，缺口如实保留。
每个主要阶段用一个段落，可在段首加粗“时间＋判断”标识，不将各阶段分别扩展为独立章节。
段落说明这一阶段的特征、关键证据及与前后阶段的联系，穿插必要的代表性指标。
数值明确是期末值、区间中位数或范围；阶段描述对应滚动信号状态，
不直接认定为策略转型。

全程总览让读者看清基金是持续增值、阶段性突出，还是低谷后反复修复。
正文承接阶段之间值得解释的问题，例如为何相对领先仍在而增值幅度下降，近期修复是否已反映到长期表现。
历史梳理与解释在同一段落中完成，避免先完整讲一遍阶段，再另设章节重复解读。

以下角度共同构成判断，按问题自然融入文章：

- **优势的水平与持续性。** 结合 Alpha 正负、量级和同组位置，辨别绝对增值与相对领先。
  从完整历史中观察优势是否在不同阶段重复出现，重要低谷是否改变整体评价。
  排名靠前但 Alpha 收窄，与增值水平和排名同时改善，应形成不同判断。
- **近期与长期的关系。** 看近期表现是在延续、修复还是削弱原有优势，以及变化持续了多久。
  长期排名较好而近期转弱时，说明原有优势与当下状态的分歧；近期先改善、长期随后回升时，
  可以解释修复过程。选择关键转折展开，稳定阶段概括即可。
- **优势对应的配置背景。** 结合长期期限、信用暴露历史与同日同组暴露分位，说明基金偏向
  高等级普通信用债、二级资本债与银行永续债、政金债或较低评级普通信用债中的哪些风险来源。
  自身暴露下降仍可能高于同组多数基金，两种比较一起帮助读者理解配置定位。
  配置解释收益优势发生的背景，不能仅凭暴露与 Alpha 同时变化，就指定某种配置为 Alpha 的来源。

若发生转型，当前评价以新策略阶段为重点，历史表现作为背景；同时考虑长期估计窗口是否仍跨越新旧策略。
配置内容服务于收益表现的解释，详细久期复盘留给相应分析任务。

## 模型解释口径

字段与查询见[Alpha 历史](../references/alpha-history.md)、[Alpha 截面](../references/alpha-cross-section.md)
及[字段字典](../references/fields.md)。以下用于内部理解，按具体发现取用。

- 240日 Alpha 是联合估计期限与利差暴露后的平均未解释收益，年化值不是基金该年的实际收益或累计超额。
  全程与阶段概括使用信号水平、范围及变化，不将重叠窗口的 Alpha 相加或复利链接成累计贡献。
  相邻窗口高度重叠，连续多日为正或排名领先不能作为多次独立成功的证据；持续性结合不同阶段判断。
- 60日状态沿用长期风险暴露衡量近期收益偏离，不是独立重估的短期 Alpha。
  配置明显迁移时，这种偏离也可能受到新旧风险结构差异影响；是否影响当前结论需结合实际变化说明。
  日均残差与年化 Alpha 比较时先对齐单位。
- 两项业绩排名都在同日、同分支、同久期组内计算，数值越高越靠前。分组可能变化，
  排名改善需结合信号本身变化理解，不将组别切换造成的位置变化直接归为能力提升。
- 截面提供四类长期利差暴露及各自的同组分位；历史接口提供暴露值，不含暴露分位。
  需要相对定位时查询相同模型日的截面，历史排名需用对应日期的截面，不能套用最新分位。
  不同因子的分位分别反映各自同组位置，不能相加或当作组合风险贡献比例。
- 因子的资产含义参见[字段字典中的因子解释](../references/fields.md#因子的投资含义)。
  AA＋相对国债的暴露包含共同信用利差影响，分位较高不独立证明信用下沉。
  暴露强弱也不等于实际仓位或优劣；长期暴露分位不替代30日模型的当前风险排名。
- Alpha 已在模型内考虑相应风险暴露，不按暴露分位高低再次扣减或加分。
  现有结果支持评价收益优势的特征，具体选券、交易或择时来源需要另外的证据。

## 表达方式

标题和开头让读者理解基金的收益特征，例如优势较持续但近期转弱，或经历低谷后修复。
用少量关键比较解释变化，正文不逐期复述曲线，也不把综合得分当作分析结论。
配置用资产名称表达，同组位置按实际比较范围命名。

内部口径不自动写成正文。通过“240日年化 Alpha”“同类相近久期组”等准确名称消除歧义，
只说明实际存在且会改变结论的限制。例如，明显转型且长期窗口仍覆盖旧策略时，
解释它如何影响近期修复的判断；一般的方法说明在用户询问时再展开。

## 成文示例

以下为不同情形的示意段落，展示判断与证据的关系，不作为固定章节或基金结论。

**全程总览。** 已知基金在数个阶段表现较强，也曾出现负 Alpha，最近一轮走弱后正在恢复。可以写成：

> 该基金的收益优势曾在多个阶段重复出现，但强度起伏较大。历史上既有较强的增值阶段，
> 也经历过负 Alpha 和明显收窄，因此更突出的特征是低谷后多次恢复优势。
> 当前长短期表现重新靠前，已走出最近一轮低谷，增值幅度仍低于此前强势阶段。

**修复与配置背景。** 已知基金曾在不同阶段表现较好，随后走弱，近期状态持续改善且长期 Alpha
由约0.5%回升至1.1%；普通信用债暴露在同组靠前，银行二永债相关暴露相对较低。可以写成：

> 该基金在普通信用债相关风险较突出的配置背景下，多次表现出收益优势，目前正在经历低谷后的修复。
> 近期表现改善后，长期年化 Alpha 也由约0.5%回升至1.1%，修复已有长短期指标的相互支持。
> 较低评级普通信用债相关暴露虽较自身过去下降，在相近久期的同类基金中仍偏高，
> 当前仍需结合这一信用配置特征理解其收益表现。

**相对领先但增值收窄。** 已知同组排名保持靠前，长期 Alpha 却由此前约2%降至0.6%。可以写成：

> 基金在相近久期的同类中仍有相对优势，但自身增值幅度已经收窄。
> 年化 Alpha 从此前约2%降至0.6%，说明排名保持领先并不意味着收益优势仍处在原有强度。
