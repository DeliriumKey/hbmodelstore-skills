# 含权基金时序多因子模型

用 252 日显式回归查询含权基金的 Alpha、股票风格及信用债／转债暴露。
模型标识：`equity-fund-timeseries-factor`，与纯债基金 240 日 Alpha 分开。

| 任务 | 读取 |
| --- | --- |
| 查询单基历史、同日分类截面或生成交互图 | [查询与绘图](references/query.md) |
| 理解因子、样本与指标计算 | [计算与字段](references/fields.md) |

使用 `get_equity_factor_info`、`get_equity_factor_history`、`get_equity_factor_cross_section`
和 `get_equity_factor_comparison`（发布状态见 capabilities.json）。
普通查询直接走 MCP，已有完整 JSON 时离线重绘，不重复查询。

方法说明用 `get_doc(path="/docs/models/equity-fund-timeseries-factor/construction")`，验证实验用
`get_doc(path="/docs/models/equity-fund-timeseries-factor/model-validation")`。
文档工具不可用时读取同源 [模型构建 Markdown](https://api.delirium.com.cn/llms.mdx/docs/models/equity-fund-timeseries-factor/construction/content.md)
或[模型验证 Markdown](https://api.delirium.com.cn/llms.mdx/docs/models/equity-fund-timeseries-factor/model-validation/content.md)。

## 文字分析（按需读取）

涉及结果解读、比较、原因解释或判断时，读取对应 analysis；按问题选用，不要求完整复盘。

| 分析任务 | 入口 |
| --- | --- |
| 解读单基 Alpha 表现、变化及同类差异 | [Alpha 表现解读](analysis/fund-review.md) |
| 理解股票风格、股债敏感性及暴露变化 | [风格与暴露解读](analysis/exposure-review.md) |
| 比较同类位置或指定基金的历史差异 | [同类与多基金比较](analysis/cross-section.md) |

综合分析从 Alpha 表现解读进入，同时读取风格与暴露解读：先认识基金的风格及其在同类中的位置，
再理解 Alpha；需要相似基金对照时读取同类比较。各页也支持独立的专项分析。

单基金综合分析中的同类参照仍属于该基金分析。用户指定多只基金并要求比较时，
以这些基金为平等对象，进入[多基金比较](analysis/cross-section.md#指定多基金比较)，不替换成某一只基金的近邻报告。

常规分析聚焦 Alpha 的水平、持续性、历史变化及同类位置，并结合实际收益理解表现。
风格先讲规模和价值在完整同类中的位置，解释偏大盘／小盘、偏成长／价值的含义；
动量等只在明显改变理解时补充，不能挤掉前两项。风格是比较背景，不是逐项解释模型的任务。
R²、MSE、条件数等留给用户明确要求的模型诊断，
不在基金分析中例行讨论，也不换一个诊断指标继续展开。
未参与所讨论回归的因子直接略过。`cb_enabled=false` 时，正文不写转债零系数、
季报占比或关闭时间，也不专门写一段解释“转债不构成解释因素”；开关仅用于内部选样。

### 成稿标题

总标题写明基金或比较对象与分析主题。单基金分析的章节使用固定主题名“风格特征”“Alpha 表现”“同类比较”；
指定多基金比较使用“风格差异”“表现比较”“阶段变化”。
以固定主题为前缀；本节有明确、重要的发现时，优先写成“主题：简短判断”，让标题直接提示发现，补充须有本节证据支持。
仅作背景介绍或结论复杂、不宜简短概括时，只保留主题；各节可混用两种形式，不为整齐而全部加或全部不加。
所有标题不加章节序号。措辞正式、简短，不用口语化比喻、口号、夸张判断或堆满细节的长句。
只固定主题名称，不固定段落、表格或篇幅；专项问题只保留相关章节，内容重复时合并到最贴切的主题，不凑齐栏目。

开头用两三句话表达判断及最重要的反差，不先堆背景信息。
综合分析先帮助读者认识基金的主要风格及同类位置，再理解 Alpha；历史与同类对照围绕判断组织，
不为分章节重复同一组数据。
不要把最新值、排名、日期与历史统计压进首段；必要的数字随正文证据展开。
常规单基综合分析约 900—1200 字；表格承接细节后，叙述可相应缩短，不另补文字凑满篇幅。
专项问题按需缩短，不硬凑栏目。
开头判断保持简短，主体章节通常用一至两段展开：先说明发现，再用历史或同类对照解释
这一发现怎样改变对基金的理解，保留会修正判断的重要反例。段落之间自然衔接，不各写一句就结束。
篇幅是参考，不设逐节配额；少报数字是精简读数，不是省掉解释，也不为达到字数补写未经核对的判断。
每节围绕一个主要问题展开，用对照解释发现，不把扩写变成更多统计或指标释义。
同一个发现不同时报最新值、历史峰值、分位、名次和持续天数，也不在不同章节重复报数。
常规正文不报精确排名和样本总数；风格位置用“规模靠同类较低的一侧，价值更偏低”等关系说明。
没有数据表时，才按需要用少量关键数字支撑判断；通常用整数或一位小数，精确统计留在底稿。
用户要求详细复盘时再展开，不为填满章节补写无关内容，也不在结尾重复总结。
身份、覆盖日期与天数、分类沿革和计算定义留在图表或底稿；用户询问或确实影响当前判断时再说明。
用直白的话说明关系：“在同类中更靠前”，而不是“截面位置抬升”；直接写“Alpha”，
不反复加“读数”。风格先说偏大盘、偏成长等含义，不用一串系数和分位代替解释。
少报数字不等于只写“表现较好、仍待观察”：保留具体变化、重要反例及它们对判断的影响。

### 文字与表格

表格展示数据，风格标签、优劣和变化判断留在正文。需要风格或相似基金数据表时，
调用[分析表格脚本](references/query.md#分析表格)，直接使用其 Markdown 输出：

- 风格表展示因子暴露、同类中位数与同类百分位，不把数值改成“偏大盘”等结论。
- 同类表展示本基金及所选 5–10 只相似基金的代码、名称、Alpha、252 日收益和全部有效因子暴露。
  市场、规模、价值、动量均保留，实际参与回归的信用债、转债也展示；不因正文只谈两项就删其他列。
  不用组中位数替代具体基金，正文解释整体差异与重要例外。

历史表现不设预制表型或专用表格命令。Agent 按结论需要自行决定是否插表、展示哪些日期或统计；
不要求每次列年末、阶段或持续时长，文字与交互图已能说明时就不插表。
表格是可选的表达工具，不要求每篇或每节都有。已有接口与计算结果提供数值和对照对象，
不为填表另选有利样本或新造评分。数值一格一个值，代码与名称分列；
简短表注说明比较日期及必要口径，区分最新值、阶段均值和峰值。
先安排数据表，再写正文。已经出现在任一表中的数值，不在正文或开头结论中复述；
不通过四舍五入、粗略比例、括号或换到另一节再报一次。同类表已有最新 Alpha 和收益时，
讨论 Alpha 时直接解释历史变化，不先重报最新值；风格表已有系数与分位时，正文解释偏向及同类位置。
表前简短交代比较对象，表后讨论关系、变化和含义，而不是把各行改写成句子。
未列入表格的历史对照或组内汇总确实改变判断时，可补充少量关键数字，
不为少报表内数字而另造一串统计。表格承接细节后自然缩短文字，不补同义解释或无关专题凑篇幅。

## 执行取舍

已有完整快照与配套交互页时直接复用，分析任务不重新开发图表或做截图验收。
将本次判断所需的历史核对与比较集中计算；先确认已有资料是否足以回答问题，
仅为会改变结论的缺口补查，不默认补齐每年截面、扩展对照或逐项诊断。
用户另要绘图时使用现有共享渲染器，查询、分析与绘图仍分别交付。
