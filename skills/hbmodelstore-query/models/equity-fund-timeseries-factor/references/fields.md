# 计算与字段

## 回归

基金日收益减无风险收益，对 `MKT + SMB_EP + VMG_EP + MOM + CREDIT + CB` 做带截距 OLS。
窗口为 252 个中国交易日，至少 240 个有效观测。不加隐含因子，不做 Alpha 中性化。

| 因子 | 含义 |
| --- | --- |
| MKT | A 股市场组合收益减无风险收益 |
| SMB_EP | 总市值按中位数分大小，与 EP 的 30%/70% 分组交叉；小盘组合均值减大盘组合均值 |
| VMG_EP | 高 EP 组合均值减低 EP 组合均值；EP = 1 / PE TTM，保留负 EP |
| MOM | 后复权价格 `P[t-21]/P[t-252]-1` 分组，赢家减输家 |
| CREDIT | 中债信用债总财富指数 CBA02701.CS 的日收益减无风险收益 |
| CB | 中证转债指数 000832.CSI 的日收益减无风险收益 |

股票样本不剔除最小 30%。规模排序使用总市值，加权使用自由流通市值；至少 120 日有效
价格，各分组至少 10 只股票。月末形成、次月固定份额持有，仅对已持有股票缺价前填。
无风险收益为当日 Shibor 3M（M0017142），`(1+年利率/100)^(1/252)-1`，不滞后、不按周末追加计息。

## 样本与季报

初始份额覆盖普通股票型、偏股混合型、平衡混合型、灵活配置型、偏债混合型、混合债券型
一级、混合债券型二级、可转换债券型基金；被动指数与增强指数不纳入。
保留历史身份，分类按历史样本，训练窗口内须持续属于覆盖类型。

季报分别在报告期之后的 5/8/11/2 月 1 日可用。最新可用报告的转债占净值比例 ≥0.5%
启用 CB，否则固定系数为 0；已确认空值按 0。训练窗口内可用季报的港股占比最大值
>0.5% 时剔除，等于 0.5% 保留。

基金净值不前填、不跨缺口计算日收益，模型日必须有实际净值。
正式覆盖不加规模、持有期、行业分散或经理集中度限制；这些是选基实验条件。
数据采用 Wind 口径，包含已核验的历史替代区间。

## 指标

| 字段 | 含义与单位 |
| --- | --- |
| alpha_daily / alpha_annual | 日回归截距／日截距×252；小数，0.05 表示 5% |
| return_252 | 固定 252 个中国交易日收益，`NAV[t]/NAV[t-252]-1`；小数，端点缺失为空，不按有效观测数调整 |
| beta_* | 因子敏感度；无单位，可为负，也可大于 1，不等于持仓权重 |
| r2 / adjusted_r2 | 样本内拟合优度／调整后拟合优度，不是预测准确率 |
| mse | 日小数收益率残差的均方误差；不是年化波动或百分数 |
| condition_number | 标准化设计矩阵的条件数，较大时关注系数稳定性 |
| train_start / train_end / n_train | 固定交易日回归窗口起止日／有效观测数 |
| cb_enabled | 转债因子是否启用；关闭时 beta_cb 为结构性 0，不表示没有任何转债风险 |
| report_date / report_available | 使用的季报期末／可用日期 |
| cb_weight_percent / hk_window_max | 转债占净值比例／窗口内港股占比最大值；百分数，0.5 表示 0.5% |
| cb_confirmed_empty | 转债报告值已确认空，不是接口请求失败 |

本模型没有提供显著性 p 值、基金排名或组合回测。不能从 Alpha、R² 单独推出显著超额或买入结论。
