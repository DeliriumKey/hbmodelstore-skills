# Alpha 截面面板组件

## 计算口径

截面在一个共同模型日读取含权基金的已计算结果，不为每只基金各取个人最新日。默认使用全模型共同
最新日及普通股票型基金样本，也可指定模型日与覆盖范围内的其他基金类型。

年化 Alpha 与252日收益以百分比表示，市场、规模、价值、动量、信用债和转债暴露为无单位回归系数。
`cb_enabled=false` 表示未启用转债因子、未估计该项暴露，不表示基金没有任何转债风险。

## 应用场景

| 场景 | 使用方式 |
| --- | --- |
| 比较同一类型基金的当期 Alpha | 固定共同模型日和基金类型后排序，定位横向较高或较低的对象 |
| 按风险暴露筛选后续研究对象 | 使用市场或转债暴露排序，再进入单基历史查看变化与同类风格位置 |
| 查找特定基金的同日模型结果 | 在完整筛选结果中按名称或代码搜索，保留相同日期与类型口径 |

## 不适用场景

| 场景 | 原因或替代方式 |
| --- | --- |
| 用部分样本概括完整同类分布 | 完整同类位置应使用同类比较面板组件 |
| 混合不同基金类型直接评价优劣 | 类型的收益目标和风险暴露不同；比较优先限定同类 |
| 从单日截面推断风格或 Alpha 的历史变化 | 截面只说明当日位置；变化应使用单基或多基金历史面板组件 |
| 把排序结果当作显著性检验或买入建议 | 模型不提供 Alpha 显著性 p 值，截面排序也不是组合回测 |
| 套用纯债基金的久期分组或 240／60 日混合得分 | 本模型是 252 日含权基金显式回归，两套模型的窗口与指标不同 |
| 将正式覆盖理解为各类基金都有相同的选基有效性 | 八类覆盖说明模型提供结果，不代表各类型的选基验证结论相同 |

## 查询

先用 `get_equity_factor_info` 取得真实可用日期、基金类型及各日样本量，再调用
`get_equity_factor_cross_section`。省略日期时使用共同最新日；指定日期无结果不向前回退。
`q` 筛名称或代码，`total` 为筛选后总量，`has_more` 为真时增加 `offset` 继续读取。
排序字段和分页上限以 MCP schema 为准。

需要落盘单页结果时使用：

```bash
python3 "$SKILL_DIR/models/equity-fund-timeseries-factor/scripts/query.py" \
  cross-section --category 普通股票型基金 --output cross-section.json
```

导出保留单页及分页元数据，不伪装为完整截面。需要形成同类位置、比较结论或选择相似基金时，
转入[同类风格与相似基金比较](peer-comparison.md)及[同类与多基金比较](../analysis/cross-section.md)。
