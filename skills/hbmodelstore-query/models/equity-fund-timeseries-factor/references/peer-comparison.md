# 同类风格与相似基金比较面板组件

## 计算口径

比较固定目标基金、模型日、二级分类、模型版本和回归规格，在完整同类样本中计算风格位置，
并选取 5–10 只暴露最相似的基金。默认使用全模型共同最新日；目标在该日无结果时保留缺失，
不以其个人最新日替代共同模型日。

同类风格位置逐列使用全部有效同类样本，保留 `percentile_below` 到
`percentile_at_or_below` 的并列区间；越低只表示暴露系数越小，不表示基金更差。
目标未启用转债因子时不比较该项暴露。

相似基金只按因子暴露选择，不使用 Alpha、252 日收益或业绩排名筛人。以完整同类池的
总体标准差缩放市场、规模、价值、动量和信用债暴露；目标启用转债时再加入转债暴露，计算均方根距离。
零方差列略去，距离并列按精确代码排序，并排除目标自身。候选不足时保留实际数量；缺少目标暴露或
所有列零方差时不生成近邻，但仍可使用有效的完整同类位置。

## 应用场景

| 场景 | 使用方式 |
| --- | --- |
| 判断基金当前风格在同类中的位置 | 使用完整同类分位，而不是少量近邻的局部分布 |
| 在相近暴露背景下比较 Alpha 与收益 | 先按暴露选定 5–10 只近邻，再比较目标与这组基金的表现 |
| 为单基综合分析选择可解释的对照对象 | 结合因子差异与相似度距离，判断候选基金是否适合用于比较 |

## 不适用场景

| 场景 | 原因或替代方式 |
| --- | --- |
| 把当前近邻称为历史上一直风格相近 | 近邻只按指定模型日选择；历史相似度需在相应时点重新计算 |
| 用近邻样本代表整个基金类型 | 近邻服务于匹配暴露后的比较，完整同类位置由独立统计给出 |
| 将组内表现差异直接归因为选股或择时能力 | 暴露匹配不构成收益归因，也不排除其他未建模差异 |
| 用相似度距离评价基金优劣 | 距离只描述暴露接近程度，不是质量、Alpha 或风险评分 |

## 查询与输出

调用 `get_equity_factor_comparison(fund_code, model_date, peers=5)`；`peers` 在 5–10 中预先选定，
不根据结果改人数。分类、版本和规格取目标当日记录，不手填类别。综合分析时通常将模型日固定为
单基历史末日。接口最多处理 10000 只同类基金；参数与错误契约以 MCP schema 为准。
保留 `factor_scales`、距离与实际候选数量，供核对选样依据。

需要保存结果时使用：

```bash
python3 "$SKILL_DIR/models/equity-fund-timeseries-factor/scripts/query.py" \
  comparison --fund-code 040001.OF --date 2026-10-09 --peers 5 --output comparison.json
```

已有完整 `comparison.json` 时，可用 [查询辅助](query.md#分析表格) 的表格命令输出风格表或近邻表；
不重新选择近邻或计算同类分位。将它与相同基金、相同末日的历史快照交给
`visualize.py --chart style-position --comparison comparison.json` 可单独展示同类风格位置。
比较这组基金的表现历史时，分别读取目标与近邻的完整历史，调用
[多基金 Alpha 比较绘图单元](multi-fund-history.md)，将它们的日频年化 Alpha 放在同一张图里。
分析判断见[风格与暴露解读](../analysis/exposure-review.md)和
[同类与多基金比较](../analysis/cross-section.md)。
