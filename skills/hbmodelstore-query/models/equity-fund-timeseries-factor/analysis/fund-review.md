# Alpha 表现解读

涉及 Alpha 水平、基金表现变化或持续性的解读时参考；按问题选用，不要求完整复盘。
历史口径与绘图见[Alpha 与收益表现](../references/fund-history.md)，同类与近邻口径见
[同类风格与相似基金比较](../references/peer-comparison.md)。以下用于判断当前问题，呈现方式沿用根 Skill。

## 研究呈现

先回应用户关心的 Alpha、风格或比较问题，解释关键发现及会修正判断的反例。
风格用于选择比较背景，历史与同类对照用于检验当前认识；这些是可选研究线索，不是固定章节。
标题、篇幅与 HTML 交付沿用根 Skill。单基 Alpha 与收益组件用于观察自身变化及同类位置；选定多只对照基金后，使用
[多基金 Alpha 比较绘图单元](../references/multi-fund-history.md)在一张图里比较。
进一步研究可以转向历史持续性、风险暴露或相似基金，
结合实际发现说明为什么值得继续，由用户选择后展开。

## 文字与表格

表格展示数据，风格标签、优劣和变化判断留在正文。需要风格或相似基金表时，调用
[分析表格脚本](../references/query.md#分析表格)：风格表保留因子暴露、同类中位数与同类百分位；
同类表保留目标及所选 5–10 只基金的代码、名称、Alpha、252 日收益和全部有效因子暴露，
不用组中位数替代具体基金。

历史表现不设固定表型。按结论决定是否插表、展示哪些日期或统计；文字与交互图已能说明时不插表。
数值一格一个值，代码与名称分列，表注只交代比较日期和必要口径。先安排数据表，再写正文；
表中已有的数值不在正文以四舍五入、括号或换节方式重复。表前交代比较对象，表后解释关系、变化和含义，
不逐行改写。表外历史对照或组内汇总只有在确实改变判断时才补充。

## 要解释什么

用户需要综合理解时，先回答：这是什么风格的基金，现在的 Alpha 表现有什么值得注意的变化。
首段写判断，不写数据摘要；身份、日期、覆盖与定义已在图中，不再作为分析开场。
随后先按[风格与暴露解读](exposure-review.md)说明主要风格、同类位置及重要变化，
让读者先认识基金，再看业绩。将 Alpha 历史与滚动收益结合起来解释，
将同类位置与相近基金对照用于回答相关问题，避免为同一问题另拆重复章节。
讲清发现、对照及其含义，不压成读数加一句结论。
扩写优先补足已有证据之间的联系：风格位置怎样帮助选择比较对象，历史高位与持续时间
是否给出不同评价，相近基金的表现怎样支持或修正当前判断。选择适用的关系展开，
不将每项都变成固定问答，也不把所有算过的结果都写进正文。
围绕当前问题取舍，先解释关键反差，再判断哪些风格或同类问题值得后续研究。
数字只承担证明这一反差的作用。历史表现不预设表型，是否插表、比较哪些日期或统计由 Agent
根据当前结论决定；没有必要就只用文字与已有交互图，不为表格专门划分历史阶段。
需要表时从核验结果组织数值，不用表替代解释；风格与同类数据表使用
[查询辅助](../references/query.md#分析表格)中的脚本。
表里已有最新 Alpha、收益与风格数值时，正文不重报，直接解释当前特点与历史变化。
历史未附表时可保留少量有用的日期或数值对照，不为每个判断都另配一组数字。

把实际收益与 Alpha 放在一起看：赚钱是否伴随相对因子模型的改善，当前好表现是反复出现，
还是仅集中在一段？讨论持续性或完整历史特征时，回看全部有效历史以免漏掉反例，但只展开改变判断的重要转折。
例如本轮水平高于过去、持续时间却更短，这一取舍比罗列历年中位数更有用。

用户追问一段上涨、下跌或回撤的原因时，按[结合市场环境解释涨跌](exposure-review.md#结合市场环境解释涨跌)
将同期实际净值、历史因子暴露与[市场因子表现](../references/factor-returns.md)连接起来。
先解释市场和风格环境与基金表现的关系，再用Alpha和相近基金对照检验这一解释；
不把一段涨跌直接归结为经理能力，也不只重复基金当前的风格标签。

只有出现需要对照才能回答的问题时，才进入[同类与多基金比较](cross-section.md)；
风格位置比较覆盖整个同类，相似基金则用于进一步对照表现。对照的作用是检验解释，
不是凑出一组一好一坏的例子，也不是再写一篇独立报告。
不写未启用转债因子的任何背景段落；季报占比、零系数和开关沿革都留在底稿。
R²、MSE、条件数等只在用户明确要求模型诊断时讨论，不换一个诊断指标例行展开。

已有完整快照与配套交互页时直接复用；将当前判断需要的历史核对与比较集中计算，
只为会改变结论的缺口补查，不默认补齐每年截面、扩展对照或逐项诊断。
用户另要绘图时使用现有共享 renderer，查询、分析与绘图分别交付。

## 判断的内部核对

以下用于形成准确判断，不照搬为正文的口径说明。计算定义见[计算与字段](../references/fields.md)。

- **水平与变化分开。** 负值也可能在改善，低于同类中位数也可能相对上升。
  基金与同类中位数的变化只支持水平、位置的比较，不是来源分解；“改善主要来自基金自身”
  或“并非风格带来”也属于来源判断，不能由差距拉大或两只相似基金表现不同推出。
- **历史断言要实际检验。** 写“首次、唯一、全部、最长”前，在完整序列上检查同一个条件及反例；
  尤其不要把“本轮更强”写成“过去没有”。全年、年内截至日、连续正值段分别计算，
  历史数据起点不当作模型发布日。叙述分段不能抹掉其中重要的相反表现。
  全部历史用于核对反例，不意味着成稿必须写全历史结论。默认写“相较某时点”或“在这段时间”，
  不从两个端点推定首次转型；低分位也不等于接近历史最低值。
  排名留在底稿，正文用“历史高位”等准确概括，不写第几高或样本总数。
  已发现过去有较长正值阶段，就将它作为本轮的直接对照，不再概括为“过去零散、最近才连成一段”。
  只查了若干年末截面，就写“这些年末时点”，不能扩成“这些年多数时候”。
- **比较不制造验证标准。** 历史最长持续时间只作对照，不是超过后就能确认可持续的门槛；
  较长或最长的一段不一定是紧邻当前的“上一轮”，按实际先后顺序命名。
  没有相应检验，不另立天数、分位或风格切换的确认规则，也不为收尾强加预测或观察清单。
- **暴露与归因分开。** Alpha 已联合考虑模型因子；beta 是敏感性，不是仓位、交易行为或收益贡献。
  beta 的大小不能说明某因子贡献了多少收益，动量暴露变正不等于经理在追涨。
- **共同变化不等于共同来源。** 少量基金的同步或相关性，只说明这些对象有相似表现，
  不能量化共同收益来源或推广至整类基金；当前相近的暴露也不能解释整段历史差异。
  当前低于目标不等于这段时间没有改善。写“同步走强／未走强”需要明确区间并实际比较历史变化；
  仅有当前值时，只写当前领先或落后，不能再推出整个类别是否普涨。
  对照基金的 Alpha 上升，只说明其数值改善；要说它的同类相对位置改善，须另核对它当时的同类位置。
- **滚动读数与期间业绩分开。** `return_252[t] = NAV[t]/NAV[t-252]-1`，相邻读数的分母也在变。
  只有该字段时，只能比较滚动收益读数；不能用 `(1+R₂)/(1+R₁)-1` 重建净值、计算期间收益
  或回撤，也不能用收益率降幅描述“赚到的收益缩水”。没有实际净值和进出窗口收益，
  不推断“近期不再创造超额”“主要是早期强势留在窗口中”。该问题无需另补材料也能避免：删去这些判断。
  Alpha 与滚动收益不能相减做来源分解；重叠窗口不相加或复利，正值天数不当作独立胜率。
- **证据与断言对应。** 分位区间不写成最小最大值；没有收益分布检验，不推断表现依赖少数大涨日。
  评价经理时另行对齐任期。

关键数值在内部底稿按基金、日期、字段定位。交稿前回读正文，逐一为其中最强的历史、因果或
持续性断言找到直接证据；只有少量时点的证据就保留时点限定，不写成长期规律或进入某区间的起点。
不能支持的断言直接删去或缩小范围，不靠段末追加“不能证明”的免责声明保留它。
正文只保留能支持结论的证据和解释；明细留在交互页，必要细节由小表承接。
不逐年报数、不逐项介绍因子、不附完整检查清单；身份、模型定义与分类沿革也不移到文末另堆一段。
结论已说清就结束。

## 离线事实核对

需要额外核对自身历史时，可对已保存的历史与同日比较响应运行现有脚本。
这份内部事实文件不是成稿或表格的必经步骤；同类位置和近邻直接使用接口结果，不重做全截面选样：

```bash
python3 "$SKILL_DIR/models/equity-fund-timeseries-factor/scripts/review_facts.py" \
  --history history.json --comparison comparison.json --output facts.json
```

仅做自身历史专题时可以省略 `--comparison`。输出是内部底稿，不是报告模板；不要把所有字段写入正文。

## 交稿前自检

只修订已形成的分析，不再扩展研究。逐项检查实际稿件，而不是声明自己遵守了规则：

- 回答是否解决当前问题，解释是否足以支持判断；标题、表文分工与后续研究引导沿用根 Skill。
  核对实际交付中的比较与结论，保留关键证据和反例，不以篇幅或栏目数量判断是否完整。
- 表外解释是否改变了理解，而非逐行复述？交稿前对照全文表格，删掉正文中重复的数值，
  包括近似值、括号与换算成几成的分位；同一数值出现在另一章节也算重复。
  保留由这些数据支持的关系和解释，风格和同类数据表不删减有效因子列。
  历史部分不要求附表，也不检查是否凑齐某种历史表。
  不用“读数、截面、标准化距离”等计算语言串成正文；保留变化的方向、对照和解释。
- Alpha、收益及收益差的数值直接带 `%`，beta 使用无单位小数；表格也遵守相同单位。
- 时间起点、极值与倍数比较逐一对应真实字段和计算。252 日收益的起点是净值基准日，
  不是回归首个收益日，也不是同月同日；未从实际交易日序列核准就不写具体起点。
- 每个精确断言与实际计算值逐项对照；月均与单日值不能混写。“通过”必须来自比较结果，
  不能把断言文字配上恒真条件。若底稿与正文矛盾，修正文，不调整检查去迎合已写出的判断。
- 没有直接证据的强断言缩小范围或删除；不凭四舍五入后的接近关系写“一半以下”等精确判断。
  保留对数据现象的解释，不为缩字数只留下数字。
