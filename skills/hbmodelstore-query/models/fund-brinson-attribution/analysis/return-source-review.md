# Brinson 收益来源复盘

本页只指导如何把归因结果写成分析，不增加取数或绘图步骤。操作直接按 [MODEL.md](../MODEL.md)
中的任务入口执行；已有结果时直接分析。纯取数、计算或导图不需要读本页。

## 分析思路

完整历程分析写成有章节的文章：标题点明核心判断，导语概括长期特征与当前变化，
正文用以下四个有明确小标题的章节展开。各章标题结合实际发现命名，例如“收益来源：配置与调仓主导长期超额”。
不能只有开头一个标题，随后连续堆叠阶段段落；表格也不能代替章节与段落之间的解释。
单期或专项问题按范围裁剪，不强制套用完整报告结构。

| 部分 | 要回答的问题 | 向下一部分推进 |
| --- | --- | --- |
| 全程总览 | 实际、静态持仓与模型基准的累计表现如何？主要增值来自哪里？ | 累计贡献是否掩盖不同阶段的差异？ |
| 阶段演变 | 主导收益来源如何变化？配置、选择、调仓是共同增值还是相互抵消？ | 哪个变化需要行业与证券证据才能解释？ |
| 下钻验证 | 关键贡献来自哪些行业和持仓？是否集中？在相邻或不利时期是否仍成立？ | 证据支持多大范围的优势，是否需要修正前面的判断？ |
| 整体判断 | 长期收益特征与当前状态有何不同？ | 提出由本次发现直接导出的后续观察问题 |

全程和阶段表须覆盖全部有效区间，缺期分开；不能以若干重点期代替整个历程。
按贡献来源和方向的变化划分阶段，不预设阶段数量，不将归因分段直接认定为投资方法变化。

## 模型解释口径

围绕行业配置、行业内选择、主动调仓解释收益。按本 Skill 的分析约定，忽略费用、未建模资产
与代理误差，将 `fit_residual`（实际收益减期初静态持仓收益）作为主动调仓贡献；
`benchmark_bridge` 单列，不把包含它的最终残差整体称为调仓贡献。
资产仓位、转债等贡献重要时也应进入主线。具体字段见[字段映射](../references/fields.md)。

阶段累计贡献按各阶段重新链接，计算见[跨期计算](../references/multi-period.md)。

- 配置看相对行业权重和行业相对市场表现；选择看持仓相对行业表现。股票赚钱也可能形成负选择贡献。
- 同时看主要正负来源及其抵消。少数持仓贡献突出，不直接推广为整个组合的选股优势；
  一级行业内选择还可能包含细分行业或风格暴露。
- 调仓作为独立增值来源评价其量级、集中时期和重复性；不凭收益差还原具体买卖或投资动机。
  正贡献期数只是描述，不等于持续能力已被证明。
- 区分基金历程与经理任期。跨基金比较需对齐区间、投资范围和主要暴露；各基金模型基准不同，
  不直接按超额或选择贡献给能力排名。纯债指数代理不能用于评价久期或信用选择能力。
- 用收益率、贡献值和比较关系支撑判断；强抵消时不以接近零的净贡献计算占比。

## 表达方式

每章先提出本章判断，再用表格或具体数据支撑，最后说明其含义或承接下一章的问题。
阶段演变章用总表覆盖全程，再按关键转折组织段落，必要时加阶段小标题；
下钻验证另成一章，集中回答阶段分析留下的问题，避免把全部个股细节塞进历史叙述。
阶段章按时间解释收益来源的变化；下钻章按研究问题组织证据，不再次按阶段复述历史。
同一数字可为比较而引用，但应形成新的判断；没有新增解释的内容不另设一节重复展开。
精简的是重复读数和无关细节，保留章节结构及解释阶段变化所需的正文。
正文围绕阶段之间的变化组织，不逐行复述表格。每段用证据推进或限定一个判断，
下一段承接尚未回答的问题。例如，发现近期收益主要来自期初持仓后，进一步区分行业配置
与行业内选择；若选择贡献集中于少数证券，再检验其他持仓的抵消及跨期表现。
结尾回到基金整体，不停留在几只成功股票，也不额外罗列与发现无关的观察事项。

内部核对不自动写入正文。通过准确的对象、区间和指标名称消除歧义；只有实际存在、且会改变
当前结论的证据限制才需说明，并写清它影响哪个判断。不陈述与本文主张无关的排除性说明。
例如，已标明分析区间且只评价基金，就无需另说“不等于成立以来”或“不归于某位经理”；
用户要求评价某经理而数据跨任期时，才需要调整范围或说明无法拆分。
正文直接进入分析，区间和期数放表题或来源注，单位放表头。
字段名、快照、净值锚点、链接算法及内部分析约定在用户询问方法时再解释，不集中写成方法说明段。

内部区分模型复合基准与基金合同基准，成稿用准确名称，不附带与当前判断无关的限制说明。
