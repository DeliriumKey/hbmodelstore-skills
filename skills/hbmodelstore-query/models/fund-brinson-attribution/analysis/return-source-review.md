# Brinson 收益来源复盘

涉及归因结果、收益来源、阶段变化或贡献差异的解读时参考；按问题选用，不要求完整复盘。
查询、计算和绘图按 [MODEL.md](../MODEL.md) 执行，
已有完整结果直接复用。收益来源、阶段变化、行业与持仓是可选研究方向，
按当前问题取舍，呈现方式沿用根 Skill。

## 分析重点

先回答当前问题，以下比较用于解释主要增值来源及其变化，按需选用。

- 实际、期初静态持仓和模型复合基准表现有何差异？资产仓位、行业配置、选择与调仓，
  哪些贡献占主导，哪些相互抵消？
- 主导来源是否随阶段变化？优势反复出现，还是集中在少数时期？
  按贡献来源和方向的转折组织历史，不机械逐期报数。
- 对改变整体判断的来源下钻：哪些行业、证券带来主要正负贡献，集中程度如何，
  在相邻阶段是否延续？下钻回答前面的疑问，不再把历史复述一遍。

持仓赚钱不等于选择贡献为正；配置比较相对行业权重及行业表现，选择比较持仓与行业表现。
少数证券突出时，说明优势集中在哪里，同时看其他持仓的抵消。结尾回到基金整体，
不止于列出成功股票，也不例行增加观察清单。

对影响整体判断的主要贡献来源，结合发生阶段解释：是持续发挥作用，还是集中于某次变化。
调仓结合各期实际与静态持仓收益比较，查看正负变化及主要贡献期；行业和选股结合相应明细下钻。
按当前问题选择展开，口径服务于判断。可用[离线下钻](../references/review.md)的 `effect`、
`history`、`groups` 直接取得来源分期、行业／个股沿革、所选与其余持仓对照，复用已有快照。

## 执行口径

字段见[字段映射](../references/fields.md)。按现有分析约定，以 `fit_residual` 衡量主动调仓贡献，
`benchmark_bridge` 单列；不把包含桥接项的最终残差整体当作调仓贡献，也不还原具体交易。
跨期和阶段贡献使用[跨期计算](../references/multi-period.md)的链接结果，不能直接相加。
缺期分段，行业分类标准分别保留；不同基金的复合基准不同。
这些用于计算和理解，正文不另列一节方法说明。

## 表格与图表

需要分析表时，用[分析表格](../references/review.md)生成 Markdown。
完整复盘通常选择汇总和有关行业／持仓表，逐期明细按需展示；不把所有表都摆出来。
主要正负来源一起看，不只挑正贡献。阶段分析先按相应区间复算，再出表。
净值与贡献图复用侧边栏交互网页，完整明细仍留在网页。
正文解释各来源如何共同形成结果、阶段间为什么值得区别对待，不逐行重报表格。
