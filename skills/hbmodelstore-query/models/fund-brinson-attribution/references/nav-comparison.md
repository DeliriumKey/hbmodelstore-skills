# 净值对比

## 功能

查询单个半年期内基金实际、持仓拟合、行业匹配组合、模型复合基准的日度净值，起点均为 1。

## 典型请求

“画华安创新 2022 年下半年的实际、拟合与基准净值。”

## 输入与默认值

初始份额代码及期末日期必填。返回基金身份统一采用当前代码和名称，不返回历史身份后缀。

```bash
python3 "$SKILL_DIR/models/fund-brinson-attribution/scripts/query.py" \
  nav --fund-code 040001.OF --period-end 2022-12-31
```

## 返回

`points` 以 `trade_date` 排序，包含 `fund_nav_index / fitted_nav_index /
industry_matched_nav_index / benchmark_nav_index`，以及日收益、相对净值和资产累计贡献。
复合基准由中证 800、中证港股通综合人民币指数、转债指数 000832.CSI 和中证全债构成，权重取
上一半年末披露仓位；纯债剔除转债，不用股票仓位补数或历史均值；期内买入持有，不每日恢复固定权重。
四条曲线的计算方式见本文件下方“净值曲线计算”，不需要跳转网页才能解释查询结果。

行业匹配组合将期初 A 股、港股权重替换为对应行业基准收益，转债和纯债沿用持仓拟合贡献。
期末持仓拟合与行业匹配组合之差等于股票选择贡献，不包含转债选择。缺失字段不以其他曲线替代。
堆叠图使用四项累计贡献，不直接相加净值。

## 可视化

单期四条实线的共用绘图入口见[可视化](./visualization.md)。
跨期查询与复算见[跨期计算](./multi-period.md)，离线重画见[可视化](./visualization.md)；当前跨期图展示实际、拟合与基准三条曲线。
跨期重新定基，去除共享边界日；没有完整日度数据的期不画插值线。

## 边界

不是基金合同基准。拟合不是实际交易路径。净值可以在有数据的区间裁剪，但不能由此得到任意
日期的完整 Brinson 归因；不能把半年行业/选股贡献摊成每天。

## 净值曲线计算

| 曲线 | 计算方式 |
| --- | --- |
| 实际净值 | 当日基金复权净值 ÷ 归因期初基金复权净值 |
| 持仓拟合 | 1 ＋ Σ（期初股票归因权重 × 股票累计收益）＋ 转债累计贡献 ＋ 纯债累计贡献 |
| 行业匹配组合 | 1 ＋ Σ（期初股票行业占基金净值权重 × 对应行业基准累计收益）＋ 转债累计贡献 ＋ 纯债累计贡献 |
| 模型复合基准 | 1 ＋ Σ（上一半年末资产权重 × 对应资产指数累计收益） |

累计收益均从归因期初计算至当日；A股、港股分别加总，港股收益折算人民币。股票归因权重为有效持仓按披露仓位调整后的权重；行业收益沿用模型的指数成分篮子。两条拟合曲线的转债贡献均按期初转债持仓及转股续接路径计算，纯债贡献均为期初纯债仓位乘中证全债累计收益。
