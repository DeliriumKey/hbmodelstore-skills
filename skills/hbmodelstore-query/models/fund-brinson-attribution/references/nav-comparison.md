# 净值对比

返回单个半年期内基金复权净值指数和复合基准净值指数，起点均为1。
0.6.0追加实际持仓拟合净值及四资产累计贡献；旧结果的新字段为null，不伪造拟合线。
基金代码统一采用当前身份；更名前的报告期不返回Wind历史身份后缀。

```bash
python3 skills/hbmodelstore-query/models/fund-brinson-attribution/scripts/query.py \
  nav --fund-code 040001.OF --period-end 2010-12-31
```

复合基准由中证800、中证港股通综合人民币指数、转债指数000832.CSI和中证全债组成。
四资产权重取上一半年末披露值；纯债剔除转债，不用股票仓位补数或历史均值。
它是模型解释基准，不是合同业绩比较基准。

拟合曲线按期初实际持仓计算。若展示实际与拟合两条线，用 `fund_nav_index/fitted_nav_index`；
复合基准是另一种比较，不要将其称为持仓拟合。堆叠展示用四项累计贡献，不直接相加四条净值。
