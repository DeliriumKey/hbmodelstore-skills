# 用 Brinson 回答分析问题

Brinson 用来定位收益从哪里来，再把重要贡献追到持仓。按用户的问题选择下面的分析，不要求每次走完所有步骤，也不固定成文目录。先讲有证据支持的主要发现，表格保留核对所需的数字，正文解释差异而不是逐行读数。

## 选什么查询

| 要回答的问题 | 取数与展开 | 有用的呈现 |
| --- | --- | --- |
| 这期为什么赚钱或跑输？ | `period`：区分基金收益、主动收益；找主要资产、行业贡献，再看对应股票 | 一张贡献拆解表，展开主要来源与拖累 |
| 是选对行业，还是选对公司？ | `period`：同一行业的配置、选择并看，进入该行业的 `securities` | 行业权重与贡献表，配关键股票收益对照 |
| 哪方面的表现比较持续？ | `history` 覆盖用户区间，再取重要期间的 `period` | 按时间升序的各期贡献表；比较贡献行业与股票是否重复 |
| 两只基金收益相近，做法相同吗？ | 分别查询同一期间的历史和明细，比较资产结构、贡献来源及集中程度 | 同期对照表，不直接按单期选择贡献排能力高低 |
| 公开持仓能解释多少，差异何时出现？ | `nav` 对比实际与拟合；结合 `period` 的拟合差和基准桥接差额 | 实际与拟合对照，指出偏离阶段；不要把偏离自动命名为交易收益 |
| 转债在组合中起了什么作用？ | `period` 先看转债市场层，再看 `convertible_bonds` | 转债配置与选择、关键券及其正股联动贡献 |

命令见[历史](./history.md)、[单期](./period.md)、[净值](./nav-comparison.md)。分析用 API 返回值；需要核实计算口径时，按 Skill 的 `model-docs` 入口读取网页最新文档。

## 从总收益追到行业、股票

先回答“赚了多少”和“相对什么多赚或少赚”，不要混成一个问题。模型复合基准不是基金合同基准；它的资产权重随基金而异。基金上涨也可能跑输基准，股票赚钱也可能拖累行业内选择。

单期先比较四资产配置、股票行业配置、股票选择、转债选择和残差的量级。市场层选出值得解释的部分，再查行业：

- 配置贡献看市场内相对行业权重，以及该行业相对本市场的表现。不要只凭“行业上涨”判断超配有效。
- 选择贡献看基金行业组合是否跑赢对应行业基准。配置与选择可能相互抵消，不能只挑正的一项。
- A股与港股分开看；同名申万行业也不是同一收益基准。先保留市场标签，再做明确标注的合计。

行业对照使用 `portfolio_market_weight` 与 `benchmark_market_weight`；`portfolio_nav_weight` 是占基金净值比例，不能拿它直接减市场内基准权重。建议表中保留行业、两项市场内权重、行业组合及基准收益、配置贡献、选择贡献。涉及资产结构时另给市场层权重。

对主要正负行业，查看其中 `included_in_attribution=true` 的股票。用 `actual_return_contribution` 找绝对收益来源，用 `excess_selection_contribution` 找行业内超额来源；股票表保留代码、名称、归因权重、股票收益、`comparison_return` 和两类贡献。优先解释改变结论的持仓，不必把全部明细搬进正文。

例如股票占净值5%，自身涨20%，行业基准涨30%：绝对贡献是+1个百分点，行业内选择贡献是−0.5个百分点。这是计算示例，不是真实基金数据。

如果选择贡献主要集中在少数股票或同一细分赛道，写清贡献集中在哪里。一级行业内的“选择”仍可能包含子行业、大小盘或风格差异；需要解释公司业绩、基金经理判断或实际交易时，再查相应材料，Brinson 数字本身不提供这些原因。

## 多期与基金比较

使用请求范围内全部已发布期间，列明实际覆盖的起止时间和期数；不要只取表现最好的几期。跨期比较贡献方向、主要行业和关键股票，关注同一来源在不利期间是否仍有贡献。若评价某位经理，任职区间另行核实，不能把基金全部历史归给现任经理。

当前接口提供独立半年期，没有多期贡献链接结果。可以逐期比较，不能把贡献简单相加后称为累计或年化超额。行业标准变化处保留体系标签，不凭同名强行拼接。日度点只是该半年期的路径，不等于新增了独立的归因样本。

比较基金先对齐期间、投资范围和主要资产暴露。各基金复合基准的权重不同，主动收益不是对同一个固定组合的排名；贡献较高也可能是仓位较高。用行业组合相对基准的收益辅助区分权重与表现。不从有限候选推断全市场排名，也不把连续若干期为正写成已证明的持续能力。

## 转债与拟合差怎么用

转债先回答配置比例及相对转债指数的选择贡献，再用逐券的行业联动、正股选择、债性部分、转债其他解释其绝对收益。需要了解转债背后的行业暴露时，可按正股行业汇总这些绝对贡献，但不称为一套独立的“转债行业配置效应”。回归β只描述当期历史联动，不用于估计未来 Delta；价格终止后使用指数续接的券，结合 `terminal_proxy_applied` 说明代理处理。

实际基金与拟合净值的差异，可定位静态持仓解释不充分的阶段；实际与复合基准的比较回答的是另一件事。看 `fit_residual` 和 `benchmark_bridge`，不要把它们与 `residual_effect` 混用。拟合较好不证明选股能力，闭合误差接近零也不证明持仓完整。纯债部分使用指数代理，不能据此评价久期、信用选择或杠杆融资成本管理能力。

## 出结果时核对

- 收益率、权重用百分比；对基金收益的贡献用百分点或基点。API 的0.01对应1%、1个百分点或100基点，按字段性质标注。
- 资产、行业、股票是下钻层级，不是三笔额外收益；转债内部四项也不能再次加进总主动收益。正负抵消明显时直接报贡献值，避免用接近零的净贡献作占比分母。
- 排名和汇总只使用进入归因且非空的值。股票返回上限500行、转债1000行；达到上限时，明细可能不全，不能宣称已穷尽最大贡献者。未披露、未纳入、旧结果新增字段为null、缺少有效期间，都不能补成零。
- 单期表说明采用期初持仓、归因区间与模型基准；涉及结论的覆盖不足或代理处理集中说明一次，不在每段重复免责声明。

这些用法参考了实际机构报告的总贡献—行业—持仓分析方式；具体案例和来源见[网页文档](https://api.delirium.com.cn/docs/models/fund-brinson-attribution)，不照搬其他模型的基准、频率或多期算法。
