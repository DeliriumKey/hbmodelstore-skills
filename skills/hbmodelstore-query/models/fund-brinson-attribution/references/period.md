# 单期归因明细面板组件

## 计算口径

单期归因按初始份额归并基金身份，分别统计基金汇总、四资产、股票行业、股票和转债贡献。四资产、行业和证券层是同一收益来源的逐层展开，不能跨层相加；行业权重比较使用市场内组合权重与市场内基准权重。

行业分类按归因期初确定：`2021-12-31` 前使用申万 2014，自该日起使用申万 2021。股票仅对满足归因条件的记录计算贡献，被排除记录保留原因。转债沿用模型已计算的历史回归 β；报价终止后的续接按等值转股计算正股收益，不表示基金实际发生了转股或赎回。

## 应用场景

| 场景 | 使用方式 |
| --- | --- |
| 定位单期主要贡献来源 | 从基金汇总下钻至资产、行业和证券，比较同层的主要正负贡献 |
| 核对行业配置与选择 | 同时查看市场内组合/基准权重、组合/基准收益和配置/选择贡献 |
| 解释个股或转债贡献 | 保留归因权重、比较收益、纳入状态及转债续接标记，避免只看最终贡献 |

## 不适用场景

| 场景 | 原因或替代方式 |
| --- | --- |
| 推断期内真实买卖 | 明细基于期初披露持仓静态复盘，不含逐笔交易 |
| 将排除证券当作零持仓 | 未参与归因不代表没有持仓，应结合披露权重与排除原因理解 |
| 将转债 β 当作定价 Delta 或预测信号 | β 是历史回归参数，语义和用途不同 |
| 跨多个半年期直接加总 | 应使用跨期收益归因面板组件的链接结果 |

## 查询与绘图

“解释华安创新 2022 年下半年收益主要来自哪里。”

普通查询使用 `get_brinson_period`，工具参数以 MCP schema 为准。期末日期必填，不自动切换到最近一期。
输入初始份额代码，返回身份统一为当前代码和名称。`included_in_attribution` 标记是否纳入归因，
`exclusion_reason` 记录排除原因；`terminal_proxy_applied` 标记报价终止后的等值转股续接。

```bash
python3 "$SKILL_DIR/models/fund-brinson-attribution/scripts/query.py" \
  period --fund-code 040001.OF --period-end 2022-12-31
```
