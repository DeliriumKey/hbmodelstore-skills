# 跨期计算与区间衔接

本文件描述 Skill 客户端派生，不改变生产模型的独立半年期口径。计算由 `scripts/analyze.py`
执行，不要求每次分析重新实现公式。

## 获取与复算

先解析初始份额；不指定区间时使用最多 40 个已发布半年期，不缩成最近两年。
先用 `get_brinson_history` 确认报告期，再按所选区间的 `period_ends` 分别调用
`get_brinson_periods` 与 `get_brinson_navs`，明细、净值各一次批量请求。
将三次完整结果导出为 JSON，再导入分析脚本，不重复取数：

```bash
python3 "$SKILL_DIR/models/fund-brinson-attribution/scripts/analyze.py" \
  --history-json /tmp/brinson-case/history.json \
  --details-json /tmp/brinson-case/periods.json \
  --navs-json /tmp/brinson-case/navs.json \
  --start 2022-01-01 --end 2022-12-31 \
  --output /tmp/brinson-case/analysis.json

# 原始快照离线重算，可限定到快照内的子区间
python3 "$SKILL_DIR/models/fund-brinson-attribution/scripts/analyze.py" \
  --input /tmp/brinson-case/analysis.raw.json --output /tmp/brinson-case/recomputed.json
```

导入接受原始 API 对象或包含 `structuredContent` 的完整 MCP 结果；使用客户端文件导出，
不手抄聊天中的截断内容。导入与离线复算都不联网。基金不一致、重复期或导出漏期会报错；
接口明确列出的 `missing_periods` 保留为缺口，不补零。
若客户端不能导出完整结果，可直接用 `analyze.py --fund-code 040001.OF --start 2022-01-01 --end 2022-12-31 --output /tmp/brinson-case/analysis.json` 保存完整快照并分析。

输出 `*.raw.json` 原始快照及 `brinson-analysis-v1` 分析 JSON。先检查 CLI 摘要、
`coverage / warnings / segments`；`overall=null` 时按连续段报告，不拼成整段累计结果。
已有快照离线复算；缺字段、校验失败和缺期不补零。网络故障允许一次重试，仍失败保留诊断。
不重算任意日期归因、不生成不存在的每日行业贡献、不运行 Wind 或生产回补。

## 可汇总区间

- 以 `period_start / period_end` 的相邻完整半年期检查连续性，不以返回行相邻判断。
- 自然年 `2022-01-01~2022-12-31` 使用 `2021-12-31` 净值锚点；7 月 1 日同理。
  其他非半年边界请求仅保留完全覆盖的半年期，明确边缘未归因，不按天数摊分。
- 缺期、未通过消费端一致性校验的期、未确认兼容的方法变化会拆成独立段。
  同 `method_id` 的普通修复版本可以同段；不同方法不自动认定可比。
- `history` 最多 40 期；达到上限只是查询边界，不证明更早没有结果。
- 份额在流程前解析；历史行业按市场、标准、代码分别汇总。申万 2014/2021 不按同名硬拼。

## 累计收益与 Cariño 贡献

每期实际与基准收益为 rF,t 和 rB,t，各期原始不重叠贡献 e[j,t] 的和等于 rF,t − rB,t。

```
RF = product(1 + rF,t) - 1
RB = product(1 + rB,t) - 1
k,t = (log(1 + rF,t) - log(1 + rB,t)) / (rF,t - rB,t)
K   = (log(1 + RF)   - log(1 + RB))   / (RF - RB)
E,j = sum(e[j,t] * k,t / K)
```

当分子分母同为 0，系数使用极限 `1 / (1 + r)`，总区间亦同。收益必须大于 −100%。
各期同一系数应用于全部相对贡献及其明细，保留层级可加性。`sum(E,j) = RF - RB`。
资产、行业、股票、转债层不能彼此相加；绝对收益贡献不能套上这组相对归因系数。

`relative_return = (1 + RF)/(1 + RB) - 1` 单独保留，不作为上述闭合目标。
调整后贡献依赖所选总区间；加一段历史会改变旧期的调整系数。因此保留原始半年贡献与
`link_factors`，不把调整数冒充原始单期数据，也不把它们当作每日信号。

方法来源：[Cariño, Combining Attribution Effects Over Time](https://tsgperformance.com/product/combining-attribution-effects-time/)，
实现参考：[R-Finance Carino](https://github.com/R-Finance/PortfolioAttribution/blob/master/R/Carino.R)。

## 日度曲线

每期从 1 开始，乘以上一期已衔接末值；共享交易日只留一条。期初和期末实际交易日可以早于
报告日，不能简单要求 12 月 31 日一定有交易。校验归一初值、终值与同一期收益一致。
日度包缺失或相邻包边界不一致时拆开路径，不插值补洞。收益与归因仍可在完整汇总数据上
计算，但必须说明日度展示不完整。页面只展示实际返回的日期。

基准在半年边界更新上一半年末权重，期内买入持有；跨期拟合在边界更新完整持仓。
不能说它们是全程固定权重的组合，也不能说它们等于真实经理交易路径。

## 解释顺序

先区分实际基金与拟合，再区分成分篮子与官方基准；最终残差已含桥接，不重复加。
转债逐期沿用模型已经计算的 β 和终止续接贡献，不在 Skill 重新估计、跨期平均或外推。
模型是事后复盘；公布日期、持仓锚点、经理任期和评价区间是不同的时间概念。

## 网页预览的默认区间与计算口径

下表说明预览的默认呈现。Skill 分析仍按用户指定的完整半年期区间取数，不因网页默认最新连续段而忽略更早的有效区间。

| 项目 | 计算方式 |
| --- | --- |
| 展示区间 | 以最新已发布一期为终点，向前取最长连续半年期；遇到缺期、方法变化或未通过校验的结果即停止。同方法的普通修复不拆段，最多查询 40 期；仅有一期时展示该期 |
| 累计收益 | 实际、持仓拟合及模型复合基准收益分别按期复利衔接 |
| 跨期贡献 | 使用 Cariño 链接，表格与归因查询一致以 % 展示收益率贡献；七项贡献合计为基金与基准的累计收益率之差，不是净值比值收益 |
| 半年期归因历史 | 仅展示当前连续区间内的各期原始贡献，转债三项合为转债选择合计；柱形净和对应各期超额收益，不能直接相加为跨期贡献。仅一期时不重复画 |
| 日度净值 | 保留全部返回交易日，按上一期末净值衔接，共享边界日只保留一次；缺失时断开展示，不插值、不缩短归因区间 |
| 股票行业贡献 | 行业配置与行业内选股贡献之和；不同市场和行业标准分别汇总 |
| 个股选择贡献 | 相对所在行业的选股贡献，不是个股绝对盈亏；同一证券跨行业口径时分别列示。支持市场、行业筛选及股票名称或代码搜索，点击表头对筛选后的全部明细排序，每页展示 20 项；筛选不改变归因区间和平均权重的分母 |
| 累计持仓权重 | 各归因期的期初披露持仓占基金净值比例之和，不应用 Cariño 链接系数，可能超过 100%，不代表当前仓位。仅统计纳入归因的记录，同一证券跨行业口径时分别累计 |
| 平均单期权重 | 累计持仓权重除以区间全部半年期数；某期没有该归因记录时按 0 计，已出现记录若缺少权重则显示为空，不按 0 补齐 |
| 资产与转债贡献 | 资产贡献包含对应配置与选择子项；转债贡献包含正股行业配置、正股选择和其他超额，不含资产配置项。不同层级不能重复相加 |
| 逐期表现与贡献 | 保留原始半年期数值；其中配置、股票选择和残差列不含转债三项超额，不能单独加总为全部主动收益 |

## 分段与调仓贡献

阶段分析对各子区间重新执行现有链接计算，不能直接小计全区间贡献。
调仓 `fit_residual` 与桥接 `benchmark_bridge` 分别乘以各期 `link_factors[period_end]` 后求和，
二者之和应等于链接残差。实际与静态组合的累计收益差不等于链接调仓贡献。
调仓正负期数从 `fit_residual` 统计，不能用残差的 `effect_stability` 代替。
行业、证券长期排名使用同一连续区间的链接贡献，不把单期排名当作长期排名。
