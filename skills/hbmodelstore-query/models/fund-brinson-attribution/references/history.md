# 历史汇总

使用初始基金代码查询最多40个半年期，默认按期末倒序返回。历史上因更名、转型或代码复用
产生的Wind身份后缀由API通过基金份额映射自动归并，用户不需要输入`!1`等历史代码。
返回的基金代码和名称统一采用当前身份，同一只基金不会因更名拆成多条历史序列。

```bash
python3 skills/hbmodelstore-query/models/fund-brinson-attribution/scripts/query.py \
  history --fund-code 040001.OF --limit 40
```

新版四资产配置、股票行业配置、股票选择、转债选择与残差合计为主动收益。
残差包含真实基金与期初持仓拟合的差异，以及成分篮子和官方指数的基准差额，不单独代表交易能力。
各行是独立半年期，没有经过多期贡献链接；不得简单加总成累计归因。
