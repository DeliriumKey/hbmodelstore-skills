# 单期收益归因面板组件

## 计算口径

归因期间为从上一半年末到所选期末的完整半年，默认使用最新已发布期。基金身份按初始份额归并。

单期以期初完整披露持仓静态复盘 A 股、港股、转债和纯债。七项贡献为四资产配置、股票行业配置、股票选择、转债正股行业配置、转债正股选择、转债其他超额和残差，合计为基金与模型复合基准的收益差。行业与证券是同一笔贡献的下钻，不与上层重复相加。实际仓位和持仓取归因期初，基准资产权重取更早一个半年末；股票归因权重按披露仓位调整。

A 股、港股行业分别统计，组合与基准权重均为各自市场内权重。行业分类随期初切换：`2021-12-31` 前为申万 2014，自该日起为申万 2021。未纳入归因的证券保留披露权重与排除原因。转债分解不含资产配置项；转债 β 与终止续接规则沿用模型结果。

实际净值、持仓拟合、行业匹配组合和模型复合基准均从 1 起算。实际净值来自基金复权净值；持仓拟合使用期初股票、转债和纯债持仓；行业匹配组合把股票替换为对应行业基准；模型复合基准使用上一半年末四资产权重。收益与贡献均以百分比表示。

## 应用场景

| 场景 | 使用方式 |
| --- | --- |
| 解释某个半年期的收益来源 | 先看七项贡献，再沿四资产、行业和证券逐层定位主要正负来源 |
| 区分持仓解释与实际基金表现 | 对照实际、持仓拟合、行业匹配和复合基准净值，识别选择与残差发生的位置 |
| 核对行业或个券贡献 | 在同一期、同一市场和当期行业标准内比较权重、收益与贡献 |
| 为跨期复盘选择重点阶段 | 根据各期贡献的异常或转折，识别需要进一步解释的阶段 |

## 不适用场景

| 场景 | 原因或替代方式 |
| --- | --- |
| 还原基金半年内的真实交易路径 | 单期使用期初披露持仓静态复盘；残差也不能直接解释为纯交易能力 |
| 将模型复合基准当作基金合同基准 | 复合基准按上一半年末资产权重构造，两者定义不同 |
| 将行业、证券和资产层贡献相加 | 各层是同一收益的不同展开，必须在同层内比较 |
| 用一个半年期判断持续能力 | 单期只描述该归因期；阶段演变应使用连续半年期的跨期收益归因 |
| 将缺失或被排除持仓视为零 | 缺失表示未取得结果；被排除证券可能仍有披露持仓，只是未参与归因 |

## 查询与绘图

普通查询先用 `get_brinson_history(fund_code=..., limit=40)` 取得可用期，再对所选 `period_end` 调用 `get_brinson_period` 和 `get_brinson_nav`。工具参数以 MCP schema 为准；不要构造未发布期末。达到 40 期只表示查询边界，不代表更早没有结果。

```bash
python3 "$SKILL_DIR/models/fund-brinson-attribution/scripts/query.py" history --fund-code 040001.OF --limit 40
python3 "$SKILL_DIR/models/fund-brinson-attribution/scripts/query.py" period --fund-code 040001.OF --period-end 2022-12-31
python3 "$SKILL_DIR/models/fund-brinson-attribution/scripts/query.py" nav --fund-code 040001.OF --period-end 2022-12-31
```

把完整 `{history, detail, nav}` 保存为 JSON 后生成与网页同源的交互 HTML：

```bash
python3 "$SKILL_DIR/models/fund-brinson-attribution/scripts/visualize.py" \
  --input snapshot.json --period-end 2022-12-31 --output-dir /tmp/brinson-preview
```

没有快照时可用 `--fund-code 040001.OF` 在线查询；不指定 `--period-end` 时绘制最新已发布一期。输出包括七项贡献、四资产分解、行业与持仓明细，以及四条单期净值曲线。明细上限为市场 4 行、股票 500 行、转债 1000 行，达到上限时必须提示可能不完整。字段解释见[结果字段](./fields.md)，文字分析另读[收益来源复盘](../analysis/return-source-review.md)。
