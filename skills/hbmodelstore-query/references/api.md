# 统一 API 约定

- 基础地址：`https://api.delirium.com.cn`
- 访问方式：公开只读，无 API Key
- `200`：查询成功；结果数组为空表示当前条件无数据
- `422`：参数格式、数量、日期范围或业务枚举不合法
- `503`：数据库只读安全检查失败或数据服务暂不可用
- TLS 握手、DNS、连接中断或超时没有业务响应体，属于网络访问故障；不得解释为空数据或模型
  未发布。可重试一次，仍失败时保留原始错误并说明当前环境无法完成在线验证。

模型发现使用顶层 `scripts/client.py`；具体模型查询使用
`models/<model_key>/scripts/query.py`。这些脚本固定主机名和路径，只暴露受约束的业务参数，
并以 JSON 输出成功或失败。不要通过修改脚本临时访问未发布路由。
