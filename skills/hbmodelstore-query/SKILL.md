# hbmodelstore 模型查询与分析

**MCP 提供数据与模型文档，Skill 组织查询、分析与绘图。** 数据与文档查询共用 `hbmodelstore` 远程 MCP。本地分析、绘图和更新脚本需要 Python 3.11+，使用标准库即可。

按任务选择模型入口，由对应 MODEL.md 路由到查询参考或 analysis 文档。涉及结果解读就参考相关 analysis，

## 取数与基金身份

- 普通查询直接调用能力清单中的 `mcp_tools`，参数以客户端发现的工具 schema 为准。
  Reference 中的 CLI 示例用于保存数据、分析和绘图，不是查询的前置步骤。
- 名称不明确时用 `search_funds`；精确份额代码需要映射时用 `resolve_fund`。已有非空
  `initial_fund_code` 就复用，不重复请求；不同基金实体无法区分时再问用户，不猜 A/C 对应关系。
- 映射成功不代表模型覆盖。按模型查询参考确认可用日期、区间和结果；不要因近期没有样本就拒绝历史查询。
- 默认区间、结果语义按对应 MODEL.md 指定的资料来源读取，工具限额以发现的 schema 为准。
  空值、零值和请求失败分别处理。
- 分析或绘图优先复用完整 MCP 导出或已有快照，按对应 Reference 导入脚本，不手抄截断的工具输出。

## 分析与交付

- 分析先回答用户的问题，再用历史、同类或贡献来源解释判断。章节使用模型约定的主题；
  有重要发现时写成“主题：简短判断”，没有时只保留主题，不加序号、不凑齐栏目。
  只需短答的场景保持一段话。方法、校验和通用边界留在执行过程，不附例行免责声明。
- 涉及结果解读、比较、原因解释或判断时，读取对应的 analysis 文档，参考其口径组织回答，
  不以用户是否明确说“分析”为触发条件。按问题选择相关内容，不要求执行完整复盘或输出全部章节、表格；
  一段简短结论也适用。仅返回数据或生成图表、不作解读时，可以不读取。
- 按用户请求确定交付深度，参考 analysis 不等于启动完整流程。优先复用已有结果，
  只为当前判断所需补查数据；不因读取 analysis 而自动增加取数、表格、网页或长篇报告，
  也不为必要的解读额外询问是否开始分析。同时要求绘图与分析时，网页就绪后先提供链接，再继续分析。
  网页所需的取数、归因计算与校验照常完成，不因暂不撰写分析而省略。
- 纯数据查询交代必要的基金身份、实际覆盖、关键值和单位，不倾倒 JSON。文字分析直接进入判断，
  不机械重复图表已有的身份和覆盖说明。没有披露期或模型日时不补点。
- 分析表格一格一个值，保留必要单位；不在数值后拼接计数、分子分母或说明。
  额外信息确有必要时独立分列，否则省略；代码与名称分列。表头和单元格不添加加粗标记。
- 表格呈现数值，正文解释比较结果、变化及其含义。有表时，正文默认不重复表内数值，
  也不用括号补抄或把数值串成一句；没有表时再用少量关键数字支撑判断。
- 查询、计算和绘图按对应 MODEL.md 进入 Reference；输出中涉及解读时，同时参考相关 analysis 文档。
- **需要图表时，默认生成交互式 HTML，并优先在 Agent Harness 的侧边栏/内置网页预览中打开。**
  使用能力清单对应的同源 ECharts renderer。保留缩放、图例开关和区间选择，不用静态截图替代交互页。
  若当前客户端不能预览，提供本地 HTML 文件或可访问链接；不假称已在侧边栏打开。
  用户明确要求 PNG、PDF、报告图片时再导出静态格式。纯数据查询不强制出图。
- 原始结果需要落盘时保存 JSON，已有 JSON 时离线分析/重绘，不重复取数；分析表格可直接输出
  Markdown，不要求另存派生统计文件。大结果通过原生完整文件导出或现有取数脚本落盘，
  不能从聊天上下文拼回数据；文件放在用户工作目录或临时目录。

## 方法与更新

- 字段与计算说明：按对应 MODEL.md 指定的来源读取。打新模型统一读取文档 MCP；
  本地 Reference 保留脚本使用、分析步骤和交付检查，不复制模型手册。
- 检查或更新本地 Skill：见[自助更新](./references/update.md)，仅在用户要求时执行。

本 Skill 只消费公开结果，不运行模型或写库。
